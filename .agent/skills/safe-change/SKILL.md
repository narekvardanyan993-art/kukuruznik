# Safe Change Skill

Этот скилл обязателен к применению при ЛЮБОЙ правке сцены, рендера или сайта (HTML/JS/CSS).

## Порядок действий

1. **Перед правкой**:
   - Назови, какие файлы будут изменены.
   - Строго запрещено трогать другие файлы.

2. **Снятие скриншотов "до"**:
   - Запусти скрипт `node .agent/skills/safe-change/scripts/snapshot.mjs before`.
   - Скрипт заморозит время и анимации, дождётся полной загрузки сцены/кадров и сохранит 6 фиксированных ракурсов + вид страницы (ширина iPhone) в формате PNG в `docs/snapshots/before/`.

3. **Внесение правки**:
   - Сделай заявленные изменения в коде.

4. **Снятие скриншотов "после" и автоматическое сравнение**:
   - Запусти `node .agent/skills/safe-change/scripts/snapshot.mjs after`.
   - Скрипт сохранит новые снимки в `docs/snapshots/after/` и автоматически попарно сравнит их с `before` (через pixelmatch).
   - В консоли будет выведен процент изменившихся пикселей для каждого файла. Порог: `< 0.5%` = «без изменений». Кадры с бОльшим отличием будут сохранены как визуальный diff в `docs/snapshots/diff/`.

5. **Откат в случае поломки**:
   - Если изменилось то, что не должно было измениться (процент > 0.5% для статичных кадров), **немедленно откати правку** (`git restore <file>` или `git reset --hard HEAD`).
   - Сообщи о неудаче. ЗАПРЕЩАЕТСЯ "чинить сверху" сломанное состояние.

6. **Коммит и отчёт**:
   - Если всё штатно: одна задача = один коммит.
   - В финальном ОТЧЁТЕ перечисли, какие проценты выдал скрипт по всем 7 снимкам, подтвердив успешность правки.
