# Шаг 2 — сбор фото (Antigravity)

Модель: Antigravity, сильнейшая модель Pro из списка, обычный режим — рутина по списку, думать почти не надо.
Что будет делать: ~20–40 минут качать и подписывать архивные фото. Запасной исполнитель — агент Sonnet 5.5 medium тем же текстом.
Перед запуском заменить `<…>`. Координаты — из энциклопедии: ошибка в 400 метров даёт ноль находок (проверено на эталоне).

```
ЗАДАЧА: собрать архивные фото здания «<название>» (<город>) в папку work/<slug>/ref/: скачать, подписать, сложить листы. Ничего не рисовать.

РАЗРЕШЕНО: сеть — pastvu.com и commons.wikimedia.org; писать только в work/<slug>/ref/; временные скрипты — только в /tmp.
ЗАПРЕЩЕНО: любые другие папки репозитория; git (commit, push, ветки); аккаунты и пароли; удалять файлы.

ВХОД: координаты <lat>, <lon>; здание стояло <год1>–<год2>; слова для подписей: <рус.>, <арм.>, <англ.>.

ЧТО СДЕЛАТЬ:
1. pastvu, https://pastvu.com/api2 — метод photo.giveNearestPhotos, params {"geo":[lat,lon],"distance":600,"year":Y,"year2":Y+4,"limit":30,"skip":0}. За вызов приходит не больше 30 снимков: идти окнами по 5 лет от <год1 минус 10> до 2000 и, пока приходит ровно 30, повторять со skip 30, 60.
2. Отобрать снимки по словам в подписи и по месту (сам объект, его улица и площадь, это место после сноса). Для каждого — метод photo.giveForPage, params {"cid":N}: взять y, dir, regions, title, desc, source, author, w, h, file.
3. Скачать https://pastvu.com/_p/d/<file> в work/<slug>/ref/pv<cid>_<год>.jpg.
4. Wikimedia Commons: найти категорию объекта и файлы по трём названиям; скачать, записать автора и лицензию.
5. Открыть КАЖДЫЙ скачанный файл и записать, что на нём видно. Тот же снимок светлее, крупнее, раскрашенный или зеркальный — пометить как дубль.
6. work/<slug>/ref/index.md — таблица: id | ссылка на страницу снимка | год | регион по странице | направление | что видно | размер | автор и source | дубль чего | это наш объект: да / нет / не уверен.
7. Листы для глаз: work/<slug>/ref/sheet_1.jpg, sheet_2.jpg … — по 4–6 фото, под каждым id. Порядок: объект до сноса; окружение; после сноса.

ГОТОВО, КОГДА: index.md и листы на месте; у каждой строки есть ссылка и регион; в отчёте одной цифрой — сколько РАЗНЫХ точек съёмки объекта до сноса.

В КОНЦЕ — только отчёт одним блоком кода: найдено / скачано / разных ракурсов объекта / что не открылось / пути к листам. Не пиши, что делать дальше, не давай команд и советов, не объясняй.
```
