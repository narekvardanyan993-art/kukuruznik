# Ролик chka.am

Ты пишешь сценарий (файл сцен) и собираешь ролик шаблоном. Код шаблона не меняешь, ничего не рисуешь.
Рядом: `hooks.md` — 30 крючков; `rotation.md` — какой формат когда и что менять по цифрам. Форматы с примерами — `content/formats/` (начать с `README.md`).
Шаблон: `content/remotion/README.md`; папки нет — `content/template/README.md`. Имена полей — из README шаблона, смысл — отсюда.

## 0. Чем был плох первый ролик (отзыв Нарека) — четыре правила на всё
| Жалоба | Причина | Правило |
|---|---|---|
| «склейка» | клипы встык, каждый начинается с нуля | движение проходит сквозь стык (§4); в сцене ≥ 2 события |
| «ничего не вылезает» | всё лежит одним слоем | в каждой сцене что-то входит отдельным слоем с пружиной (§4) |
| «плоский текст» | голые буквы поверх картинки | слово = бумажная бирка с тенью, входит как предмет (§5) |
| «дешёвый звук» | синтез, один тембр, звук на склейках | записанные звуки `content/sfx/`, только на события (§6) |

## 0б. Отзыв Нарека на pogos-03 (12.11): «лучше, но медленновато; иконки дёшево; темп держать звуками»
| Жалоба | Правило |
|---|---|
| «медленновато» | живая запись — куски ×1,5–2, паузы и ожидания вырезать; сцена без нового события > 0,5 с — резать |
| «иконки появляются дёшево» | мелочь (значок, бирка, фишка, точка, кусок линейки) входит **каплей**: масштаб 0 → 1,12 → 0,96 → 1 за ~0,25 с, на перелёте сплющена, на отскоке вытянута |
| «исчезать так же быстро» | уход мелочи ~0,18 с (короткий вдох 1 → 1,07 и схлоп) **со своим звуком исчезновения** `out`; не «гаснет» |
| «темп держать звуками» | звуковое событие минимум раз в 0,5 с, не больше двух разом, тихо (−21…−27 dB, акцент до −11); звук на каждое: буква (`key`), тап (`click`), кусок линейки (`tick`), прокрутка (`scroll`), листание/переход (`whoosh`), появление (`pop`), исчезновение (`out`) |
| «тап-тап-тап, точки, линейка» | в каждой сцене цепочка мелочей: точки (`dot`), пунктир-линейка (`ruler`, 4–7 кусочков, шаг 0,07–0,1 с, tick на каждый), тапы по месту действия |
Проверка: сборщик пишет плотность звука в `-events.json` / `-smooth.json` (`per_sec` ≥ 2, `max_gap` ≤ 0,5, `max_together` ≤ 2) и `ВНИМАНИЕ:` на каждую дыру. Запись экрана — `segs` + `crop` (README шаблона): кадры 60 к/с отбираются в 30 к/с, повторов 0.

## 0в. Отзыв Нарека на tour-01 (12.11): «слишком быстро и одинаково; нужен рассказ, как фильм; без музыки» — главнее §0б, §3 и §6, где они спорят
| Жалоба | Правило |
|---|---|
| «где надо остановиться — не останавливается» | ритм **«вдох-выдох»**: вход быстрый (капля, листание ×1,5), **пауза 1–2 с на главном** (картинка чуть живёт: парение, дрейф камеры ≤ 5 %), уход быстрый. Главных моментов 5–7, у каждого своя пауза; в отчёте — секунды пауз (`moments` в сценарии → `-smooth.json`) |
| «зумы резкие» | камера медленно: easeInOut, 1–1,5 с на движение, после наезда держать кадр ≥ 1 с; отъезд быстрее наезда (0,4–0,5 с, прячется в листание) |
| «всё по шаблону» | **каждый приём ≤ 2 раз за ролик**, приёмов ≥ 6: шторка «до/после», наезд, бирка, фишка-подпись, иконка-капля, лупа, параллакс телефона, тап-кольцо, крупный заголовок. Тап-кольцо — только на главные нажатия (не на каждую букву) |
| «линейки везде — глупость» | линейка — максимум одна и только со смыслом (настоящая высота, длина из `story.md`); нет числа — нет линейки |
| «нужен рассказ» | структура фильма: завязка (телефон, набор адреса) → знакомство (прокрутка, остановка, тап) → чудо (здание ожило, **«до/после» шторкой**: архивное фото и наш рисунок, ручка едет сама, tick на старте и финише, подписи `1930` / `chka.am`, пауза 2 с) → прогулка → магия (наклон, время суток) → финал (`chka.am` крупно, тихий последний звук) |
| «скорее всего без музыки» | **ролик без музыки**: звук несёт ролик сам. Фон «комната» очень тихо (`room`), события: в паузах реже (1 на 0,7–1 с), в движении плотнее; длинные звуки (`len`, `fade`) — прокрутка = завод механических часов `scroll_watch-*` с затуханием. Проверка тишины — `tempo.max_gap` (для такого ролика ~1,4 с), не 0,5 с |
| «подписи» | короткие простые слова латиницей (chka.am · Yerevan · 1930 · tilt · day / sunset · before / after) + значок — рядом со своим действием |
Запись экрана: стоп-кадр в паузе — тот же кусок записи на ×0,5 (у записи 60 к/с шаг отбора 1 — повторов нет); ×0,25 и медленнее нельзя (дубли).

## 1. Порядок
1. Формат — по `rotation.md`: не тот, что в двух прошлых роликах; продающий ≤ 1 из 4. Открыть его файл в `content/formats/`.
2. Материал: рисунки Gemini (`<slug>/frames/`, `tests/<slug>/frames/`), ролики Veo (`kitchen:`, `work/<slug>/`), архивные фото со свободной лицензией (`sources.md`), съёмка сайта (`capture`). Чего нет — того в ролике нет: взять другой формат, кодом не дорисовывать.
3. Крючок — из `hooks.md`, другой тип, чем в прошлом ролике. Написать кадр 0 одной фразой: что видно и что уже движется.
4. Раскадровка по секундам (таблица как в формате): сцена, камера, что входит, бирка, звук. Проверить §3 «событие в секунду».
5. Перенести в файл сцен `content/scenes/<здание>-NN.json` по README шаблона. Годы и факты — только из `story.md` / `sources.md`; спорные даты в кадр не идут.
6. Собрать, открыть лист кадров (`-sheet.jpg`), пройти чек-лист §8. Любое «нет» — править сценарий.
7. В отчёт: файл ролика, `-sfx.wav`, формат и номер крючка, строка для `posts.md` (подпись hy/ru/en — слова живут в подписи, не в кадре). Публикует только Нарек.

## 2. Крючок: 0–1,5 с
- Кадр 0 уже движется и уже самый странный кадр ролика. Нет: чёрного, заставки, названия, плавного появления, «спокойного начала».
- К 1,5 с у зрителя вопрос («что это было?», «куда оно делось?»), к 3 с понятно, о чём ролик; ответ — не раньше середины.
- Один приём на крючок: исчезновение, вопрос, герой, свет, глубина или процесс (типы A–F в `hooks.md`).
- Первый звук события — на 2–4-м кадре. Кадр 0 = обложка: читается как картинка без текста.
- Крючок понятен без звука и без слов: проверить на листе кадров, закрыв подпись.

## 3. Ритм: «каждую секунду что-то происходит, но не мельтешит»
- **Событие** = вход слоя, проявление, смена времени суток или погоды, поворот камеры, герой сделал движение. Склейка сама по себе — не событие.
- Каждые 0,7–1,2 с — одно событие. Секунда без события — дыра; два главных события в одну секунду — мельтешение.
- В любой момент: одно главное движение + фон (дрейф камеры, снег, ветер). Два главных — развести на 8+ кадров.
- Смена масштаба или состояния каждые 2–4 с: общий → крупный, день → ночь. Три сцены подряд одного масштаба — нельзя.
- Перед главным раскрытием — выдох: 8–15 кадров без новых событий и без звука. После него — самая длинная сцена ролика (1,8–2,5 с).
- Сцена 0,9–2,5 с; на 15 с — 6–10 сцен. Темп к раскрытию растёт (сцены короче), после — падает.
- Длина: 9–15 с; «история» и «трейлер» — до 20 с. Петля (последний кадр = кадр 0) — когда формат позволяет: пересмотры считаются.

## 4. Движение (30 к/с)
- **Мелочь входит каплей** (значок, бирка, фишка, точка, кусок линейки): 0 → 1,12 → 0,96 → 1 за ~0,25 с со сплющиванием (§0б); уходит за ~0,18 с со звуком `out`. **Карточка и вырезка входят пружиной**: 10–14 кадров, перелёт ≤ 6 % (Remotion `spring`: damping 12–15, stiffness 120–180, mass 1); масштаб 0,85 → 1 и сдвиг 30–60 px из-за края или из-за здания; тень «садится» вместе с предметом.
- **Крупное входит без отскока** (весь рисунок, фото): easeOut 14–20 кадров или «проявление» (тёмные штрихи первыми).
- **Уход быстрее входа:** easeIn 6–9 кадров. Вход тормозит, уход разгоняется — никогда наоборот.
- **Камера плывёт всегда:** easeInOut, за сцену масштаб ≤ 12 %; linear — только дрейф ≤ 4 %. Замершая камера = «фото».
- **Сквозь стык:** следующая сцена продолжает направление и скорость камеры (наезд → наезд) или совпадает по форме и месту (силуэт собора → силуэт памятника в той же точке). Переход ≤ 10 кадров; растворение дольше — только для времени суток.
- **Глубина:** в половине сцен ≥ 2 плана с разной скоростью — дальний 0,3–0,5×, здание 1×, ближний (ветка, снег, герой, бирка) 1,5–2×. Источник — наклон сайта (`tilt` в съёмке) и слои станка; из плоской картинки глубину не выдумывать.
- **Лесенка:** несколько элементов входят с шагом 3–5 кадров, не разом.
- Нельзя: вращения, тряска, глитч, вспышки чаще одной на ролик, отскок у зданий, линейные входы.

## 5. Текст — бирки
- В кадре только то, что читают все: год, число («8/8», «1/5», «№4»), знак («?», «→», «×», «✓»), имя латиницей (`Yerevan`, `chka.am`). Фразы — в подпись поста.
- Бирка — вырезка бумаги сайта (`engine/paper/`), чернила `#3C2D1E`, шрифт сайта, мягкая тень (сдвиг 6–10 px, размытие 20–30, 25–35 %), поворот −2…+2° (каждый раз свой).
- На экране одна бирка (две — только пара «1930 → 2026»), 1–2 слова, держится ≥ 0,8 с (год) и ≥ 1,2 с (слово). Цифры ≥ 120 px высотой, адрес ≥ 150 px.
- Привязана к месту в рисунке (год — у здания, «?» — над пустым местом) и едет с камерой чуть быстрее сцены: она ближе всех.
- Входит пружиной со звуком, уходит до смены сцены или уезжает вместе с ней. Не «проявляется» и не «гаснет».
- Стрелки, штампы, подчёркивания, рамки «от руки» — только рисунки Gemini листом; нет рисунка — нет элемента. Графика интерфейса шаблона (точка, фишка, тап, пунктир-линейка, рамка телефона) — не рисунок, её можно.

## 6. Звук
- Музыку ставит Нарек в TikTok. Наш слой — звуки событий, отдельным `-sfx.wav`. Ролик обязан быть понятен совсем без звука.
- Звук — на событие (вход, исчезновение, тап, буква, кусок линейки, прокрутка, листание), не на голую склейку. Темп: в среднем ≥ 2 события в секунду, тишина не дольше 0,5 с (кроме выдоха перед раскрытием), не больше двух разом (§0б).
- Только записанные: `content/sfx/` — `pop_*` вход, `out_*` исчезновение, `whoosh_*` карточка / страница / листание, `click_*` тап, `key_*` буква (`key_enter` — ввод), `scroll_*` прокрутка, `tick_*` линейка и мелочи, `stamp_*` штамп. Синтез (`sfx.py`) — лишь воздух и фон.
- Один файл не звучит дважды подряд; у типа ≥ 2 вариантов (пока один — шаблон сам сдвигает высоту ±4 %). Пик звука — на кадре касания (± 1 кадр).
- Уровень под музыку: события −27…−17 dB (мелочи тише), один акцент ролика до −11; уход тише входа. Перед раскрытием 0,3–0,5 с тишины. Не больше двух звуков разом.
- Нет подходящего записанного звука → событие без звука и строка в отчёт, а не «похожий».

## 7. Поля, цвет
- 1080×1920, 30 к/с. Поля шаблона `safe: [250, 600, 160]` (сверху, снизу, справа), слева 60. Бирки и главное — x 60–920, y 250–1320; адрес и главное слово — не ниже y ≈ 1250 (рекламный файл TikTok режет низ строже — 660).
- Бумага `#F3EAD8`, чернила `#3C2D1E`. Чисто белого и чёрного нет. Один акцент на ролик — тёплый свет из самого рисунка (окна, закат).
- Архивное фото — сепия, на бумаге, с рамкой. Ночь не темнее, чем на сайте. Без фильтров, свечения, усиленной насыщенности: «дорого» = мало цветов и много воздуха.
- Крупные люди — только из роликов Veo; мелкая деталь (< 40 px в кадре) зрителю не видна — подъехать или не показывать.

## 8. Чек-лист перед выдачей (да / нет)
1. Кадр 0 уже движется и понятен без звука и слов?
2. К 1,5 с есть вопрос, к 3 с понятно, о чём ролик?
3. Нет секунды без события и секунды с двумя главными событиями?
4. В каждой сцене что-то входит отдельным слоем (капля, пружина или проявление), мелочи уходят так же быстро?
5. На каждом стыке движение продолжается или совпадает форма?
6. Два плана глубины хотя бы в половине сцен?
7. Перед главным раскрытием есть выдох и тишина?
8. Слова — только бирки: ≤ 2 слов, понятны всем, с тенью, каждая ≥ 0,8 с?
9. Всё важное внутри полей, адрес не ниже y 1250?
10. Звук на каждом входе и уходе, тишина ≤ 0,5 с, ≥ 2 события/с, не больше двух разом, все звуки записанные?
11. Длина по формату; последний кадр — адрес или петля в кадр 0?
12. Формат и тип крючка не повторяют два прошлых ролика; продающих ≤ 1 из 4?
13. Всё видимое — Gemini, Veo, свободный архив, съёмка сайта; кодом ничего не нарисовано?
14. Годы и факты — из `story.md`; спорных дат в кадре нет?
15. Нет выдуманных покупателей, отзывов, «осталось N мест», если это не так?
16. На листе кадров каждая секунда отличается от соседней?
