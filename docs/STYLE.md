# Визуальный стиль сцены «Кукурузник»

Сцена выглядит как архитектурный рисунок акварелью и тушью на бумаге.
Стиль складывается из пяти слоёв (снизу вверх):

## 1. Бумага
- Фон: `#f5ecda` (тёплый кремовый).
- Зерно: ~4 000 случайных точек `rgba(120,100,74, 0.055)` размером 0.4–2.0 px.
- Виньетка: радиальный градиент `rgba(0,0,0,0)` → `rgba(92,72,46,0.13)`,
  центр чуть выше середины экрана.
- Небо: акварельный вертикальный градиент от синего к тёплому у горизонта,
  закатная полоса `rgba(240,146,84)`, ночная синева.

## 2. Заливка (тонирование)
- MeshToonMaterial с 5-ступенчатой градиентной картой → акварельный эффект
  полосатого света.
- Правило цвета: **свет тёплый — тень холодная**.
  Освещённые грани сдвинуты к золотому `(+0.04, +0.02, −0.02)`,
  теневые — к синему `(−0.02, −0.01, +0.04)`.
- Палитра: тёплый травертин `#f2e3bc`, серый базальт `#98989d`,
  тёмный туф `#7e8084`, приглушённая зелень `#7a855e`.

## 3. Штриховка (только в тенях)
- Применяется ТОЛЬКО к теневым граням (luma < 0.48).
- Диагональные полоски в локальных координатах объекта (triplanar),
  поэтому не плывут при вращении.
- Частота ~20, ширина линии через smoothstep (без муара).
- Кроссхэтч (второй набор) при глубокой тени (luma < 0.28).
- Цвет туши: `vec3(0.18, 0.16, 0.14)`, подмес 50%.
- Растворяется вдали (distance fade 10..30).
- НЕ применяется к стеклу, мелким деталям, лоджиям.

## 4. Контур (тушь)
- **Силуэт**: inverted-hull outline (BackSide с выносом по нормали).
  Толщина ~0.022, alpha 0.85. Дрожание толщины через 3D-шум
  `sin(pos.x*20) * sin(pos.y*35) * sin(pos.z*15)`.
- **Внутренние рёбра**: EdgesGeometry → ломаная из 4 сегментов с jitter.
  Перелёт за углы 0.03–0.07. Alpha 0.65.
- Цвет днём: `#2f2a25` (тёплый уголь). Ночью: `#a8b2ca` (холодный сланец).

## 5. Воздух (атмосфера)
- Вертикальный голубой градиент поверх всей сцены:
  `rgba(148,178,210, 0)` вверху → `rgba(46,55,92, 0.11)` внизу.
- Делает нижнюю часть сцены чуть голубоватой, как воздушная перспектива.
- Не влияет на FPS (CSS overlay).

---

## Где живёт стиль в коде
- `engine3d/core.js` — материал `toon()`, outline, edges, бумага, виньетка.
- `kukuruznik/scene3d.html` — CSS-слой воздуха.
- `kukuruznik/params.js` — палитра цветов.
- `kukuruznik/builder.js` — вызовы `toon()`, `addOutline()`, `addEdges()`.
