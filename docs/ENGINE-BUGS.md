## 3. Грабли процесса (то, что станок должен делать сам)

- **Проверки по реальному времени краснеют случайно** (искры, Veo-места): всё движущееся — под виртуальные часы или заморозку. `[L:s49] [L:adv-1] [LOG:2026-11-09 ≈01:25]`
- **Кэш**: каждая выкладка движка — новая VERSION; кадры с `?v=<sha>`. `[L:ver-1] [L:s24]`
- **Правки движка скриптами**: str.replace берёт не то вхождение; повторный запуск дублирует функции → вставки с меткой-охраной + проверка `grep -c function` = 1. `[L:rep-1] [L:pp-15]`
- **Коммит только после зелёных тестов** через `&&`. `[L: «Коммит — только после зелёных тестов»]`
- **Передача файлов облако→Мак портит бинарники** (C2PA, uuid в mp4) → tar + sha256. `[L:s9] [L:s23] [L:pp-27]`
- **git в VM оставляет .lock**, удалять нельзя → mv. `[L:zv2-4]`
- **Визуал проверять только рендером браузера**, не Python-имитацией; снимки с `?perf=0`, `?still=1`. `[L:s19] [L: perf=0] [L:s31]`
- **Новый тип файла кадра** — только в `FRAME_GLOBS`. `[L:pp-22]`
- **Медленные проверки**: полная check_site на Маке ~31–33 мин, CI >1,5 ч и падает. `[L:s24] [ST]`
- **Gemini-канал**: проверять в обе стороны до захода; правка — в новом чате с точным файлом; после каждой картинки строка в журнал. `[L:заход 9] [L: «Правка FIRST image…»] [L: «Длинный Gemini-заход…»]`
- **Скачанный файл Gemini может быть старым** — брать только новее клика. `[L:dl-1]`
