# Определение готовности (Definition of Done)

## Кукурузник 1.0 готов, когда:
- поворот плавный, без видимых «слайдов»;
- деревья выглядят как карандашный скетч, а не как шары;
- открывается на iPhone и крутится без рывков;
- вес одного набора (день/закат/ночь) не больше 10 МБ, сначала грузится только день;

## 1.1, после публикации
- всё остальное (новые эффекты, детали, интерьер).
