# SALES-MACHINE — машина продаж chka.am

Чертёж. Написан 10.11.2026 (шаг 7/10, параллельно с П1 станка). **Кода машины продаж ещё нет** — его пишет шаг 8 (раздел 8).
Стоит на выходе станка (`docs/STANOK.md` §1 и §8): станок выдаёт здание → машина продаж делает из него посты, заходы и деньги.
«Прикидка» = не замер; первая неделя статистики заменяет прикидку фактом. Факты о сервисах — только с официальных страниц, ссылка рядом, проверено 10.11.2026.

**Сейчас:** заработано $0. Товар один: надпись в камне на Погос-Петросе, $15, 8 мест, продаж нет.
**Цели:** первый $ — до 10.12.2026; $100/мес — к февралю; $300/мес — к маю; замена зарплаты — за 1–2 года (сумма — не в репозитории).

## 0. Шесть правил

1. **Музей — первый.** На экране здания не больше одного продающего элемента, и не на первом кадре.
2. **Сначала тест, потом стройка.** Большое делаем только после «да» дешёвого теста (раздел 3).
3. **Продаём эмоцию:** собака, старик, пара, имя в камне. Не «файл с картинкой».
4. **Каждый шаг воронки — отдельный адрес страницы.** Иначе шаг не виден в статистике.
5. **Через Polar — только цифровое.** Услуги фирмам и спонсоры идут мимо Polar (раздел 2.1).
6. **Деньги выводим редко.** Один вывод стоит ≈ $2,5–3,5, сколько бы ни выводили (раздел 2.2).

**Что Polar не разрешает** ([правила Polar][p-aup]): физические товары; услуги людей; пожертвования, сбор денег, реклама и спонсорство. Предзаказы — только после отдельной проверки. Разрешено цифровое, что отдаётся файлом, ключом или личной ссылкой.
Что из этого следует:
- **Кнопки «пожертвовать» через Polar не будет.** Вместо неё — пак обоев со свободной ценой (L1): человек платит сколько хочет и получает файлы. Свободную цену Polar умеет ([Polar][p-products]), файл отдаёт сам ([Polar][p-files]).
- **Надпись в камне** — цифровой товар с личной ссылкой; организация Chka одобрена. Риск остаётся: делается под заказ и не мгновенно. Снижаем: доставка за часы, а не дни (Д8).
- **«Оживлю дом» (L4)** похоже на услугу. До первой платной продажи советник письменно спрашивает поддержку Polar. Ответ «нет» → Lemon Squeezy или перевод.
- **Кафе, отели, спонсоры** — только перевод на счёт. Нужен способ принять деньги от фирмы (вопрос 5).
- **Принты и постеры** — не через Polar и не сейчас: спрос не проверен, Нарек сам в них не верит.

Сайт стоит на GitHub Pages, а он не для интернет-магазинов; ссылки на поддержку и сбор денег при этом разрешены ([GitHub][gh-terms], [GitHub][gh-limits]). Поэтому касса — всегда на стороне Polar, корзину на сайте не строим. Если продающих страниц станет больше музейных — переезд хостинга отдельным решением.

### 2.2 Сколько доходит до Нарека (Polar Starter, карта не из США)

Организация Chka создана 10.11.2026, то есть после 27.05.2026 — это тариф Starter, а не старые 4 % + 40¢ ([Polar][p-pricing]). Проверка — по первой продаже: с $15 должно уйти ≈ $1,25–1,48.

| Цена | Комиссия | На руки | Съедено |
|---|---|---|---|
| $3 | $0,70 | $2,30 | 23 % |
| $5 | $0,83 | $4,17 | 17 % |
| $9 | $1,09 | $7,91 | 12 % |

Вывод денег ([Polar][p-payouts]): доступны через 7 дней после продажи; вывод только вручную; минимум от $10 (зависит от валюты — смотреть в кабинете); за месяц с выводом $2 + 0,25 % + $0,25 за вывод + до 1 % конвертации.
Вывести $13,52 стоит ≈ $2,42 (18 %). Вывести $100 — ≈ $3,50. **Правило: выводим, когда накопилось $100, или раз в квартал.**
Товары дешевле $5 продвигать бессмысленно: фиксированные 50¢ съедают четверть. Возврат денег покупателю комиссию не возвращает ([Polar][p-fees]) — поэтому «переделаем», а не «вернём».

## 4. Контент-конвейер из станка

### 4.1 Что станок выдаёт из каждого здания одной командой

`stanok content <slug>` → папка `work/<slug>/content/` (вне git). Новых картинок Gemini и роликов Veo — ноль: всё режется из уже принятых мастеров, слоёв и роликов актёров.

|---|---|---|
| `clips/<кадр>.mp4` | 5–6 | 9:16, 12–15 с: день → закат → ночь → снег → шоу (`stanok clip`, STANOK §8.1) |
| `clips/show.mp4` | 1 | до/после целиком (снос → время назад) — главный крючок |
| `clips/hero_<id>.mp4` | 2–3 | крупно изюминка: собака в будке под снегом, старик с голубями, пара под зонтом; петля 6–8 с |
| `carousel/<кадр>/1–6.jpg` | 5–6 | день / закат / ночь / снег / до-после + слайд с адресом (STANOK §8.2) |
| `carousel/facts/` | 1 | 4–6 слайдов «факт + кадр» из `story.md`; источник у каждого факта уже есть |
| `sale/spots.jpg` | 1 | «свободно N из 8» из блока `sale`; обновляется после каждой продажи — повод для поста |
| `wallpapers.zip` | 1 | обои для телефона: кадры × день, закат, ночь, снег (товар L1) |
| `posts.md` | 1 | к каждому файлу: первая строка-крючок, подпись до 100 знаков на hy/ru/en, 3–5 хэштегов, адрес (`chka.am/t`, `/i`, `/f`), текст закреплённого комментария, отдельный текст-история для Facebook |

Итого на здание: 8–10 роликов и 6–7 каруселей ≈ **16 постов = 4 недели** при четырёх постах в неделю. Ленин и Погос-Петрос после переезда на e2 дают 8 недель контента без нового здания.

Автопроверки (без них папка не считается готовой):
- текст и главное на слайде — вне краёв TikTok: сверху 250, снизу 600, справа 160 px на 1080×1920 (`chka-log.md`, 09.11);
- ролик 1080×1920, не длиннее 15 с; последний кадр — адрес;
- архивное фото попадает в контент, только если в `sources.md` у него свободная лицензия; нет лицензии — в посте только рисунок;

## 6. Цифры и решения

### 6.1 Сводка раз в неделю

`tools/sales_report.py` (прогон С2) каждый понедельник дописывает блок в `chka-log.md`. Сам лог в git не входит, цифры продаж в публичный репозиторий не попадают.

```
НЕДЕЛЯ 47 (16–22.11)
Посты: 4, просмотров 410 000                  <- вписал Нарек
Сайт: 620 заходов (/t 140, /i 55, /f 80, прочее 345)
Витрина /buy: 190 -> /pay 31 -> /thanks 3
Polar: 3 заказа, $45, на руки ≈ $40,5; баланс $40,5 (вывод при $100)
Доля: пост -> сайт 0,15 %; витрина -> оплата 1,6 %
ВЕРДИКТ: Т1 = да. Дальше: С4.
```

### 6.2 Какие числа что значат

| Число | Удваиваем | Держим | Бросаем |
|---|---|---|---|
| Витрина → оплата (при ≥ 100 заходах на `/buy`) | ≥ 2 % | 0,5–2 % | 0 % при 300 заходах, после одной смены цены или текста |
| Заходы с канала в неделю (4 недели подряд) | ≥ 150 | 20–150 | < 20 — минуты уходят в другой канал |
| Продаж одного товара в неделю | ≥ 3 | 1–2 | 0 за 4 недели при живом трафике |
| Пост → сайт | ≥ 0,2 % | 0,05–0,2 % | < 0,05 % три поста подряд — менять последний слайд и призыв |

«Удваиваем» = вдвое больше постов про этот товар (но не чаще 2 из 4) и следующий прогон из раздела 8 для него.
«Бросаем» = товар остаётся тихой кнопкой, минуты Нарека на него больше не тратятся.

### 6.3 Вехи

## 7. Деньги на инструменты

Сейчас инструменты стоят ≈ $50 в месяц при доходе $0. Они окупаются с **4 надписей в месяц** (4 × $13,5 = $54). Это первая цель, раньше любых покупок.

| Что | Цена | Брать? | Честная окупаемость |

| Instagram для chka.am | $0 | да, сейчас | закрывает Д1 |
| Polar Starter | $0 в месяц ([Polar][p-pricing]) | уже есть | — |

## 8. План шага 8 — код машины продаж

Правила прогонов те же, что в STANOK §7: промпт ≤ 60 строк и ссылается на разделы этого файла; один прогон — один коммит; проверки не дольше 20 мин; `git push` и `publish_*` — Нарек.
