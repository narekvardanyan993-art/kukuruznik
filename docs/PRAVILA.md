# Правила проекта

Свод того, что уже выстрадано. Читать ПЕРЕД правками — каждая строка
здесь стоила отдельной поломки.

## Как устроена работа с файлами

- Правь только `src/engine/*.js` и `src/model/*.js`. Что где лежит — в `src/CARTA.md`.
- После правки: `python3 build.py`. Он склеит `js/engine.js` и `js/model.js`.
- `kukuruznik/js/engine.js` и `kukuruznik/js/model.js` СОБРАННЫЕ. Правки прямо в них пропадут.
- Проверка перед коммитом: `python3 build.py && node --check kukuruznik/js/engine.js && node --check kukuruznik/js/model.js`.
- Почему не настоящие модули: весь движок — одна замкнутая функция, палитра и
  время суток видны рисующим кускам только изнутри неё. Разрезать по-настоящему —
  значит переписать сотни обращений. Склейка даёт то же удобство без риска.

## Железные правила картинки

1. **Только canvas 2D.** WebGL запрещён — не работает на телефоне владельца.
   SVG, перерисовываемый каждый кадр, тоже запрещён: браузер не тянет.
2. **Объём должен быть замкнут.** У коробки все шесть граней. Пропустишь одну —
   зритель увидит пустоту внутри, это читается как дырка в модели.
3. **Всё рисуется одной очередью по глубине**, а не слоями. Каждый самостоятельный
   предмет (дом, дерево, фонарь, флаг, скамейка) получает свою глубину и рисуется
   от дальнего к ближнему. Слои давали исчезающие объекты под углами.
4. **Линия рисуется, если видна хотя бы одна из двух соседних граней.** Не обе.
5. **Порог отсечения задних граней — 0.15.** Опускал до 0.07 — башня стала
   прозрачной, крайние лоджии легли плашмя. Не трогать.
6. **Слои лоджий гаснут у силуэта** (`f.face < 0.30` для окон, `0.34` для балконов).
   Без этого по краю башни лезут белые полоски и тёмные щепки.
7. **Дальний план живёт в «небесных» координатах** со сжатием `SKY_K = 0.42`:
   Арарат, силуэт города и солнце бесконечно далеко, у камеры узкий угол обзора.
8. **Солнце привязано к миру**, а не к экрану: угол берётся из `atan2(LZ, LX)`.
   Иначе оно висит в одной точке экрана при вращении.
9. **Порядок кадра:** небо → земля и тени → поверхности и мощение → очередь по
   глубине → вывески → воздух. Менять местами нельзя, иначе тени лягут поверх домов.

## Скорость (айфон, цель 60 кадров)

- Палитра пересчитывается ОДИН раз на движение ползунка, не каждый кадр.
- `drawAir` — одна заливка на весь экран. Раньше рисовалось около тысячи силуэтов,
  это ело 3.1 мс из 5.7. Сейчас кадр 1.4–2.3 мс.
- Плотность пикселей максимум 3. При просадке сначала снижаем её до 2, и только
  потом прореживаем деревья и город. Наоборот — картинка портится раньше.
- Градиент во всю ширину должен начинаться с прозрачного, иначе по небу идёт шов.

## Содержание

- Всё армянское: флаги красный–синий–абрикосовый, надписи армянским письмом.
- Не выдумывать. Сверяться с фотографиями: башня 14 этажей, 16 рёбер, соседние
  здания — только те, что реально стояли рядом. Пропорции Арарата настоящие.

## Архивные фото — только свободные лицензии

Правило навсегда, стоило целой сессии переделки: на сайт идут ТОЛЬКО
фото с чёткой свободной лицензией — Public Domain с явной отметкой,
CC0, CC BY, CC BY-SA. Возраст фото не делает его свободным (снимок
1970-х может быть чьей-то нынешней собственностью). Источники, где
искать: Wikimedia Commons (у файла и категории справа честно написана
лицензия), Flickr с фильтром по лицензиям. Фото с PastVu — НЕ свободные
(там свои условия использования), решил в сентябре 2026, что убираю их
все, даже если уже стоят на сайте.

Каждое фото подписывается: автор, источник, лицензия ссылкой на её
текст. Если фото обрезано или пересжато для сайта — пометка
«обрезано»/«сжато» в той же подписи.

Если под здание свободных фото не хватает — вместо дыры в галерее
честная карточка «реконструкция» с кадром из 3D-сцены, а не чужое фото
без разрешения.

## Публикация

- Номер сборки — в `src/engine/01-palette.js` (`var BUILD = '...'`), он же
  виден на самой странице внизу. `build.py` сам проставляет его версией в
  загрузчик `kukuruznik/scene.html` (это сама 3D-сцена, не страница-рассказ
  `kukuruznik/index.html`) и пишет в `kukuruznik/version.txt` — руками номер
  поднимать не нужно нигде, кроме `01-palette.js`.
- Страница сама сверяет `version.txt` на сервере с тем, что у неё в кэше, и
  при расхождении один раз перезагружается — это чинит проблему «телефон
  застрял на старой сборке» без ручной чистки кэша.

## Чтобы не наступить второй раз

- Любая правка по образцу должна ПАДАТЬ, если образец не найден. Молчаливая
  замена «ничего не нашлось» однажды дала целую сборку, где новый код не попал
  в файл, а я отчитался, что всё работает.
- Не открывать файл на запись раньше, чем прочитал его. `open(f,'w').write(read(f))`
  обнуляет файл до чтения — так был потерян целый кусок движка.
- Сравнивать правки A/B-рендерами ОДНОГО ракурса. Разница между соседними
  кадрами вращения ничего не показывает: пропавшее дерево в ней не видно.

## Оформление сайта («светлый музей», с сентября 2026)

- Рисованным остаётся только контент: скетчи, архивные фото, 3D. Всё
  вокруг — чистый интерфейс. Не возвращать в интерфейс бумажную
  фактуру, сепию/желтизну фона, скотч, карандашные рамки и рукописный
  шрифт в кнопках, меню и основном тексте.
- Цвета — только из токенов в начале `assets/hub.css`. Акцент один:
  акварельная терракота `--accent` (#a3472a, белый текст на ней —
  контраст 6:1). Второй цвет — графит `--graphite`. Бирюзовый убран.
- Шрифт интерфейса — Manrope, армянский — Noto Sans Armenian.
  Рукописный Caveat — только подзаголовок «здания, которых больше нет».
- Кнопки не ниже 48px (главные — 56px), с реакцией на нажатие.
  Все анимации отключаются при «уменьшить движение».
