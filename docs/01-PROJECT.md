# Չկա — здания, которых больше нет

Сайт-музей снесённых зданий Еревана: https://chka.am/. Каждое здание — интерактивный рисунок в скетч-стиле
(«3D-фото»: наклон телефона или мыши даёт объём, день/закат/ночь, живые детали, точки-подсказки с фактами)
плюс страница с историей и архивными фото. Первое здание — «Кукурузник» (Дом молодёжи, 1979–2006).

## Для кого и как говорить с владельцем

Трафик — армянский TikTok владельца (Нарек): зрители открывают ссылку прямо в браузере телефона. Главный экран —
телефон (Safari на iPhone). Владелец код не читает: простыми словами, без названий функций и файлов, по одному
шагу, отчёт — одним блоком кода (правила ответа — в CLAUDE.md и AGENTS.md).

## На чём собрано

Чистый HTML/CSS/JS, без фреймворков и без сборщиков на стороне сайта. Сайт — GitHub Pages из ветки `main`
(домен chka.am, файл `CNAME`). Просмотрщик — WebGL (шейдер смещает кадр по карте глубины); если WebGL нет —
запасной режим из двух слоёв (фон + вырезанное здание). Старый 3D-движок на Canvas 2D (эпоха «WebGL запрещён»)
удалён на этапе 6 выноса движка — его правила (docs/PRAVILA.md и др.) больше не действуют.

## Две ветки

- **`main` — живой сайт.** Руками не правится: всё туда кладут скрипты публикации через временную копию
  (worktree во временной папке, всегда удаляется) и только после зелёной защитной проверки.
- **`test/depth-photo` — ветка разработки.** Здесь исходник движка, настройки зданий, инструменты, документация.

## Как вносятся изменения

- **Правка движка** (новая фишка, исправление): `engine/` → `python3 tools/publish_beta.py` (бета: chka.am/beta/) →
  проверка беты на телефоне → `python3 tools/publish_engine.py` (бета → все живые здания одним коммитом).
- **Правка только здания** (тексты, точки, кадры Кукурузника): `kukuruznik/building.json` → `python3 tools/publish_kukuruznik.py`
  (`--frames` — перекодировать кадры из test-assets/frames/).
- **Новое здание** — docs/NOVOE-ZDANIE.md.
- У каждого скрипта есть `--dry-run` (всё собрать и проверить, ничего не отправлять). В main — только после «ок» владельца.
- Откат — отмена одного коммита (`git revert <номер>`, номер печатает скрипт).

## Защита

`tools/check_site.mjs` — перед КАЖДОЙ публикацией, скрипты запускают её сами: снимки всех зданий и страниц
«как на сайте» против «кандидата» (кадры × день/закат/ночь × телефон и ПК, прогулка по кликам), строгое попиксельное
сравнение, fps, ошибки и битые файлы, шапка страницы и превью для соцсетей. Подробно — docs/ENGINE-PLAN.md (этапы 1, 5).
Проверку не ослаблять. Гонять только на Mac: в облаке нет видеокарты (fps 2–4, прогон — часы).

## Что НЕЛЬЗЯ

- Править живые страницы зданий руками — их собирает `tools/build_pages.py`.
- Публиковать в main без зелёной проверки и без «ок» владельца.
- Ставить ссылки на бету и тестовые здания с сайта.
- Класть в git материалы не для сайта: скачанное, черновики, заготовки — только в ~/Documents/chka-kitchen.
- Использовать фото без свободной лицензии (нужны CC0 / public domain / CC BY / CC BY-SA, автор и лицензия у каждого фото).
