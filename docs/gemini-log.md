## Ночные кадры — проверка: контуры дня на ночном кадре (лучший сдвиг ±8 px), окна светятся окнами, новых объектов нет
Все шесть приняты с 1-й попытки. Контуры дня найдены на ночном кадре: кадр 1 — 99.7%, 2 — 99.4%, 3 — 99.5%, 4 — 99.8%, 5 — 97.7%, 6 — 86.2%
(на кадре 6 ниже, потому что неосвещённые окна на ночном рисунке почти не видны; освещённые совпадают с дневными контурами по наложению).
Общий сдвиг ночных картинок относительно дня: 1–3 px по вертикали, исправлен при `finalize`.

## Что помогает Nano Banana
- Промпт «strict local inpainting of this ORIGINAL image… every other pixel must stay identical» + явное перечисление того, что убирать; без слов «trees behind it» (иначе дорисовывает лес).
- Файл нужно прикреплять заново каждый раз и проверять миниатюру в поле ввода, иначе правит прошлый результат.
- В автоматизации: первый клик по «+» и по кнопкам часто только наводит курсор; перед поиском file input нужна пауза 2–3 с; сгенерированное изображение скачивается кнопкой в правом верхнем углу картинки (после наведения).
