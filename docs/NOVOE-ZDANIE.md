# Как добавить новое здание

Здание на общем движке = папка с картинками кадров + файл настроек `building.json` + (по желанию) страница истории.
Код движка для нового здания не пишется: всё, чем здания отличаются, — в настройках. Порядок: скрытая бета →
проверка на телефоне → постоянный адрес только по «ок» владельца.

## 1. Материалы (всё сырьё — в ~/Documents/chka-kitchen/buildings/<имя>/, не в git)

- **Кадры** — рисунки в скетч-стиле (Gemini / Nano Banana). **ПРАВИЛО: кадры всех зданий — вертикальные 9:16, как у
  Кукурузника (`look.frameSize` = [768, 1365]).** Горизонтальный кадр телефон режет до правой/средней части; 2:3 у Ленина
  «плыл» при наклоне (сдвиг считается в долях кадра, а видимая ширина у 2:3 уже, чем у 9:16). Кадр другой пропорции сборка
  не принимает (`tools/building_schema.py`, допуск 1 %, тест 13 в `tools/test_build_pages.py`). Режим «соотношение сторон 9:16»
  в Gemini есть; кадр 2:3 обрезкой не спасать — композиция ломается. На каждый кадр:
  - `<кадр>.png` — рисунок со зданием;
  - `<кадр>_bg.png` — ТОТ ЖЕ рисунок без здания (та же рамка и масштаб);
  - по желанию `<кадр>_sunset.png`, `<кадр>_night.png` — закат и ночь той же рамки. Нет — движок рисует сам
    (терпимо, но проще картинки: закат — заливка, ночью окна зажигаются по маске окон).
  Как добывали кадры Кукурузника и принимали их — docs/gemini-log.md и `tools/gemini_intake.py`.
- **Референсы для Gemini** — если здания уже нет, один архивный снимок даёт выдуманное окружение (так вышел первый Ленин: площадь
  позади памятника, которой там не было). Нужны 3–5 снимков с разных сторон + кадр Кукурузника как образец стиля; сырьё лежит в
  `tests/<здание>/source/ref/` (не в git). Источники фото: pastvu.com (поиск по координатам через api2), Wikimedia. Город снимка проверять по странице pastvu (теги и координаты), а не по названию: «Памятник Ленину на площади Ленина» 240470 оказался Батуми. Права для ориентира
  генерации не важны, для самой страницы истории — только свободные лицензии (см. ниже).
- **Факты** — только с источником. Нет источника — нет факта. Тексты на hy/ru/en.
- **Архивные фото** для страницы истории — только свободные лицензии (CC0, public domain, CC BY, CC BY-SA; без NC/ND),
  с автором и лицензией у каждого. Скриншоты панорам Google/Яндекс — нельзя.

## 2. Кадры → слои для движка

Для каждого кадра нужны: цвет, карта глубины (что ближе/дальше — на ней держится наклон), фон и его глубина,
вырезанное здание, маска неба/деревьев (`_env`), маска окон других зданий (`_win2`). Кукурузник делался так
(на Mac, `.venv-depth`): `tools/build_frames.py` (глубина — Depth Anything V2 Small, вырезка — SAM) →
`tools/build_env_masks.py` (небо, деревья, окна; рамки окон подобраны по глазам) → `tools/publish_kukuruznik.py --frames`
(PNG → WebP на сайт).

**Честно:** эти инструменты пока заточены под Кукурузник (читают и пишут `test-assets/frames/`, `build_frames.py`
ещё правит старый `test-assets/depth.html`). Для второго здания их надо научить работать с папкой здания — это первая
задача при работе над Лениным. В облаке тот же конвейер работает на копиях моделей с GitHub (без Hugging Face) —
проверено на одном фото 28.09.2026.

## 3. Настройки: `<папка>/building.json`

Проще всего — скопировать `tests/test-2/building.json` и заменить. Что внутри (полное описание — docs/ENGINE-PLAN.md,
«Этап 3» и «Этап 4»):
- `meta` — адрес, заголовок и описание (для превью в соцсетях, армянский), картинка превью, значки, цвет темы;
- `text` — название, табличка, приветствие (hy/ru/en); `facts` — факты; `aboutFacts` — какие из них в панели «О здании»;
- `links` — «домой» и страница истории (`null` — нет кнопки);
- `look` — цвет дневного неба и зелени, ночь, **`frameSize` — размер кадра в пикселях, только 9:16** (`tuning` — как у Кукурузника; править
  `MAX_SHIFT_X/Y`, `BREATH_AMPLITUDE`, `ZOOM_NEAR` только если края плывут: у Ленина пол круче по глубине, чем у Кукурузника
  в 1,67 раза, поэтому числа снижены в 1,28 раза), `sunSide`;
- `frames[]` — всё про кадр внутри кадра: `name`, `hidden`, `parade`, `crop`, `flag`, небо (`sky.ref` — яркость неба
  на рисунке, `sky.end` — где небо кончается, доля высоты; `band`, `clouds`), `sun`, `lawn`, `life` (что летает),
  `hotspots` (точки-подсказки, координаты 0–1), `nightLamps`/`lamps` (фонари), `night: false`/`sunset: false`,
  если нет таких картинок;
- `tuning` — любые числа движка из `engine/config.json`, только если нужно.
Ошибки ловит проверялщик при сборке и пишет по-русски, что не так («кадр 2: нет ночной картинки …»).

## 4. Скрытая бета (так живёт здание до «ок» владельца)

`tests/<имя>/building.json` в ветке разработки → `python3 tools/publish_beta.py` → страница
`https://chka.am/beta/tests/<имя>/`: noindex, ни одной ссылки на неё с сайта. Проверка (`check_site`) обязана
быть зелёной: у тестовых зданий смотрится структура (число точек, парад, нет чужих имён, нет пустого неба ночью).
Смотреть на iPhone.

## 5. Постоянный адрес (только по «ок» владельца)

Папка `<имя>/` в корне (латиницей: адрес `chka.am/<имя>/`) с `building.json`; живые здания = все такие папки,
страницу собирает `tools/build_pages.py` на живом `engine/`. Карточка на главной: в корневом `index.html` блок
«КАРТОЧКА ЗДАНИЯ» — скопировать и поменять адрес, названия, подпись, картинку `card.webp` (из `card-source.jpg`
через `python3 tools/images.py`); заготовки «скоро» — там же. В `404.html` — имя в список `known`.
Страница истории — по образцу `kukuruznik/about.html` и `history.html` (стили `assets/story.css`, `history.css`,
галерея из `<папка>/gallery-source/` через `tools/images.py`, подпись фото — автор и лицензия со ссылкой на источник).

## Что ещё не готово (честно)

- Конвейер кадров (п.2) — под Кукурузник; обобщить под папку здания.
- Публикация НОВОГО живого здания (с 04.10.2026): здание живёт в `tests/<имя>/` (бета — `beta/tests/<имя>/`), в его
  building.json — блоки `live` (адрес chka.am/<slug>/, превью og.jpg, значки, всё, что у живого иначе, чем в бете) и `card`
  (карточка главной; необязательный `card.stack` = место `a`–`d` в верхней «стопке» главной, картинка — `card.image`),
  в index.html — метки `<!-- card:<slug> -->`. Картинка в стопке ставится сама: на место силуэта `sc-<место>`
  (`<svg class="ghost">`) при первой публикации, дальше — между метками `<!-- stack:<slug> -->`; занятое чужой
  картинкой место = СТОП (у Кукурузника `sc-d` вручную, без меток). Публикация: `python3 tools/publish_building.py <slug> --dry-run`,
  затем без `--dry-run` — одним коммитом в main: папка `<slug>/` (кадры, about, history, галерея, og.jpg, card.webp), карточка
  на главной, `<slug>` в `known` у 404.html. Дальше `publish_engine.py` пересобирает и это здание. Превью — `tools/make_og.py`
  с параметрами (пример в шапке скрипта).
- Горизонтальные кадры на телефоне режутся — кадры делать вертикальными.

### Правило слоёв: кадр вне объекта = фон (2026-10-02, Ленин)
Если есть фон без объекта, слой «кадр» (`name.webp`) вне вырезки (расширенной на 2 px) собирается из фона, а маски неба и окон считаются по фону (`ground_from_bg`, по умолчанию включено; выключить — `"ground_from_bg": false` в layers.json). Иначе остатки объекта в «земле» и дыра в маске неба при параллаксе и закатном размазывании читаются как тёмная копия объекта. Лишнее здание в кадре убирают одной и той же правкой в кадре и в фоне (пример — `tests/lenin/source/patch_left_building.py`).
