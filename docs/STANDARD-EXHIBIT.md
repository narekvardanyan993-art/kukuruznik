# Стандарт экспоната chka.am

Действует с 05.10.2026 (решения Нарека). Разбор и цифры — `docs/STANDARD-EXHIBIT-draft.md`. Как делать кадр — `docs/NEW-FRAME-CHECKLIST.md`.

## Что такое кадр
Один рисунок здания (карандаш + акварель, Gemini в аккаунте pro.gemini.one1) с одной точки съёмки, 9:16, 768×1365 на сайте.
На сайте кадр = 8 слоёв: рисунок, подложка без здания, вырезка здания, глубина, глубина подложки, маска неба/деревьев, маска окон,
+ закат и ночь картинками. Плюс блок кадра в `building.json` (небо, солнце, фонари, что летает, точки, шоу).
Кадры одного здания отличаются **ракурсом** (точкой съёмки). День/закат/ночь есть у каждого кадра — это не отдельные кадры.
Кадров-событий (снос, стройка) нет — только ракурсы.

## Сколько кадров
- Цель — **6 кадров**, как у Кукурузника.
- Минимум — **4**, если на остальные ракурсы нет честного фото-источника. Честный источник = снимок из того же города
  (город проверен по странице снимка), той же эпохи экспоната, по которому видно, что стоит в кадре слева / в центре / справа.
- Нет источника — ракурс не рисуем (окружение не выдумываем: так Ленин получил неверное место и батумское здание).
- Хотя бы один кадр — дальний план (здание в городе), по возможности один — крупный план (`closeUp`: птицы на кромке, блики).

## Точки-подсказки
- 3–4 точки на кадр. Точки берут факты из общего списка здания (`facts`): 4–6 фактов на здание хватает на все кадры
  (у Кукурузника 5 фактов на 6 кадров).
- Факт — только с источником (`sources.md`). Спорное (размеры, «лицом на север») — не в точки.

## Шоу
- Существующий парад движка, новых видов не делаем. Вид — строка `"parade"` у кадра: planes, drones, heli, fireworks, balloons,
  banner (banner — только на кадре с `closeUp`). Шоу — флаг Армении.
- Цель — шоу на каждом кадре (у Кукурузника 6 видов на 6 кадров); минимум — на одном кадре.
- Ленин: вариант (a) — существующий парад с флагом Армении (решение 05.10).

## Живость (с 06.10.2026)
Экспонат без живости не рекламируем. Эталон — Кукурузник (разбор: `tests/lenin/report/live/kukuruznik-live.md`).
**Модули, пресеты, проверенные значения и правила Нарека — `docs/ENGINE-LIFE.md` (библиотека жизни, e1.8).**
- Правила Нарека (07.10.2026): люди только мелкие и далёкие, 2–6 на кадр, на крупных планах — ноль; пути только по нарисованным
  дорогам с перекрытием (`occluders`) и оверлеем путей; стоящие машины и ларьки рисуются в картинку, не движком; вода — в картинке.
- На каждом кадре **минимум 3 постоянных движения** — идут сами, без кнопки шоу, и **заметны на телефоне за первые 3 секунды**.
- Стиль рисунка: карандаш, штриховка, лёгкая акварель; эпоха экспоната (у Ленина 1950–80-е); без мультяшности и фотореализма.
- Только то, что честно для кадра: люди и машины — там, где на рисунке есть площадь/улица/дорога; толпу и транспаранты не выдумываем.
- Чем закрывать (сначала то, что уже есть в движке):
  | Движение | Настройка кадра |
  |---|---|
  | облака плывут, солнце, одиночные птицы | всегда (`sky.band`, `sky.clouds`, `sun`) |
  | события раз в 8–15 с: самолёт, стайка, журавли, змей, шар, орёл, фонарик | `life` (день / закат / ночь) |
  | кроны качаются | карта `_env` + `wind` (1–1,2; крупный план до 1,9) |
  | тени облаков по земле и фасадам | `cloudShadow` 0,2 (крупный план 0,22–0,26; вид сверху на светлой площади 0,12 — 0,2 даёт грязное пятно) |
  | флаг на здании колышется | `flag` [x, y, ширина, высота] |
  | бабочки днём, светлячки ночью | `lawn` (газон) |
  | птица садится на кромку/голову и улетает, блики в окнах | `closeUp.perch`, `closeUp.glints` |
  | далёкие пешеходы, машины и троллейбус, голуби, стаи | `ambient` (движок e1.8, `docs/ENGINE-LIFE.md`): `walkers`, `cars`, `flocks`, `occluders`, `lightBirds` — пресеты, пути вручную по дорогам |
  | фонтаны (струи, рябь, блики) | `fountains` (движок e1.5); вода — в картинке |
  | ~~толпа, сидящие, «точки» эпохи~~ | убрано в e1.8 (выглядело мультяшно и приклеенно) |
- Ночью: своя ночная картинка кадра `<кадр>_night` (Gemini; запасной путь — `tests/lenin/source/p7_night.py`), фонари `nightLamps` со световыми пятнами, окна; людей почти нет, птицы спят, у машин лучи фар и красные огни (делает движок; `docs/ENGINE-LIFE.md` «Ночь»).
- Машины только с маской дорог `ambient.roads` из Gemini (сборка: ≥ 98 % пути на дороге, 0 точек на тротуаре, обе полосы), правостороннее движение, эпохи кадра (`soviet-1950s` у Ленина); машины и люди — спрайты Gemini из атласа; крупный план — `ambient.details` (мелочи), людей ноль. Пошагово — `docs/ENGINE-LIFE.md` «Рецепт».
- **Плотность — пересмотрена 07.10.2026 после отзыва Нарека** (старая цель «≥ 30 объектов, человек ≥ 13 px» отменена: крупные люди — кринж).
  Живость держат: стаи птиц, машины по дорогам, тени облаков, листва, фонтаны, события в небе. Люди — 2–6 мелких на кадр, на крупном плане ноль.
  - Цвет: акварель на телефоне не бледнее Кукурузника (склейка `report/live3/kukuruznik_vs_lenin.jpg`); вода — синяя акварель в картинке, струи видны.

## Обязательно до рекламы (TikTok, ссылки)
1. Не меньше 4 кадров (цель 6), у каждого — паспорт ракурса с источником (`tests/<здание>/source/<кадр>/passport.json`).
2. У каждого кадра: закат и ночь картинками (не процедурные), фонари по ночной картинке, 3–4 точки.
3. Шоу хотя бы на одном кадре; кнопка-флаг работает на iPhone.
4. Страница истории и архив (фото только со свободной лицензией), факты с источниками, армянский проверен носителем.
5. Проверка Нарека на iPhone: наклон без «плывущих» краёв, нет современных машин/знаков, город и эпоха верны.
6. Живость: на каждом кадре ≥ 3 постоянных движения, заметных за 3 с (раздел «Живость»).
Пока пункты не выполнены — экспонат живёт по адресу, но не рекламируется.
