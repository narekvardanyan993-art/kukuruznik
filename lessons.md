# Уроки chka.am

Агент читает этот файл в начале КАЖДОГО промпта по chka.am.

- Проверять город референса: однажды в кадр попало здание из Батуми.
- «Нет фото с этого ракурса» не значит «нет здания». Проверь карту и план площади.
- Местное знание Нарека важнее интерпретации агента по архивному фото. Если они расходятся, спроси Нарека, а не дорисовывай.
- Gemini не правит кусок кадра. Он генерирует только отдельный фрагмент на однотонном фоне, вписывает его агент.
- Патчи и фрагменты сохранять только в PNG (JPEG портит края).
- Не трогать _проверки во время прогона публикации.
- Gemini только в аккаунте pro.gemini.one1.
- Фикс считается сделанным только после скриншотов при крайних углах наклона, а не по «код выглядит правильно».
- Современные фото годятся только для геометрии зданий. Машины, знаки, указатели, новые фонари в реконструкцию не переносить. Каждое здание сверить по году постройки с эпохой экспоната.
- Обходить технические блокировки (CSP, буфер обмена, передача файлов) разрешено, если это внутри собственных инструментов Нарека и временно. Запрещено: вводить пароли и токены, менять настройки безопасности браузера/системы/аккаунтов, трогать любой аккаунт кроме pro.gemini.one1, отправлять файлы в сторонние сервисы. После обхода — убрать за собой и коротко указать в отчёте.
- Открытый пункт в логе/хэндоффе пишется с сутью: что именно решаем и какие варианты. Плохо: «Шоу флага — решить». Хорошо: «Шоу флага у Ленина: включать или нет; сейчас flag: null».
- Промпт для Cowork — до ~60 строк, иначе обрезается. Большое задание делить на заходы.
- check_site с зоной допуска на панели не видит изменений панели (так прошло подчёркивание 1,5 → 1 px). Панель проверяет Нарек глазами.
- Не открывать файл на запись до чтения (open(f, "w") раньше read): так обнулился 404.html. Сначала прочитать в переменную, потом писать.
- Известный ложный красный check_site: kukuruznik/history pc/top однажды отличался при неизменных файлах (2026-10-05), при повторе прошёл. Если красный только этот снимок и файлы страницы не менялись — повторить проверку один раз; повторился — разбирать, а не ослаблять проверку.
- Полоса неба кадра (`sky.band`) — только НАД объектом: движок рисует облака, птиц и прочую «жизнь» в этой полосе поверх всего кадра, без заслонения зданием. Полоса через статую = облако на груди Ленина (lenin_4, 05.10.2026). new_frame.py теперь режет полосу по верху вырезки; на скриншоте кадра проверять, что в полосе нет объекта.
- scipy `binary_dilation/erosion(..., iterations=0)` = «до упора», а не «ничего»: `grow: 0` в layers.json сделал вырезку на весь кадр (lenin_4, 06.10.2026). Настройку из конфига, которая может быть 0, передавать только через `if n > 0`.
- Коммит — только после зелёных тестов: тесты и `git commit` в одной команде через `&&`, не через `;` (06.10.2026 «lenin show» ушёл в коммит при красном test_new_frame — тест ждал у Ленина один видимый кадр).
- `main` — дерево опубликованного сайта (сборки beta/, lenin/, kukuruznik/), с test/depth-photo у него общий предок из сентября: `git merge main` в рабочую ветку даёт конфликты (docs/LOG.md, kukuruznik/*.html) и тащит сборки в исходники (06.10.2026). Не сливать. «Подтянуть живое» = сверить, что опубликованные кадры/настройки совпадают с веткой (хеши файлов `git rev-parse <коммит main>:lenin/frames/…` против tests/lenin/frames/).
- Параллакс «чинится» только замером объекта ОТНОСИТЕЛЬНО фона вокруг (небо, кроны) на крайних наклонах, а не частей объекта между собой: bldDepth 0.3 сделал голову и постамент заодно, но статуя D всё равно скользила по небу ~21 px и «плыла» на iPhone (06.10.2026). Фон рисуется по карте глубины КАДРА, движок растягивает её контраст 2–98 % — плоскость крупного плана задаётся `depthRaw` + своей картой.
- Скриншоты/гиф с живыми деталями в облаке (swiftshader) — с `?perf=0`: иначе движок через ~5 с видит fps < 45 и выключает детали, и на кадрах «ничего не движется».
- Живость проверять на телефоне по размеру, а не по числу: на B и G было больше объектов, чем у Кукурузника, но люди 4–8 css px — на iPhone это точки, площадь «пустая» (07.10.2026). ~~Человек ≥ 13 css px (`ambient.minPx`)~~ — отменено 07.10.2026: Нарек на iPhone назвал крупных людей кринжем (см. ниже).
- Автоснимки по кадрам (клик «вперёд» N раз) иногда не долистывают — клик во время перехода теряется: однажды «кадр C» оказался кадром B (07.10.2026). Каждый снимок сверять глазами с нужным кадром, прежде чем считать по нему.
- Крупные «нарисованные» люди, толпы и движковые ларьки выглядят мультяшно и приклеенно — Нарек на iPhone: «кринж» (07.10.2026, бета 5c23351). Живость — не числом людей: только мелкие далёкие, 2–6 на кадр, на крупном плане ноль; живость держат птицы, машины, тени, листва, вода. Правила — docs/ENGINE-LIFE.md.
- Пути «на глаз» по общему виду кадра ведут сквозь стены и деревья (07.10.2026: машины B ехали по кронам и крыше). Пути класть по сетке 0,025 поверх картинки, точками по середине проезжей части, и доказывать оверлеем `paths_<кадр>.jpg` в увеличении; всё, мимо чего идёт путь, — в `occluders`.
- Статика (стоящие машины, киоски) — дорисовывать в слой картинки акварелью (прозрачная заливка поверх фона + зерно), а не движком; если не встаёт честно (нет бордюра/места) — пропустить: киоск A и машины G убраны, выглядели приклеенными (07.10.2026).
- Синяя заливка воды движком поверх штриховки (multiply) даёт «узор» — воду запекать в картинку (tests/lenin/source/p5_water_g.py), движок рисует только струи/блики/рябь.
- Одинаковый цикл полёта у всех птиц и тёмные силуэты на видах сверху сразу видны как «повтор»: у каждой птицы свой ритм и окна планирования, стая меняет форму, голуби сизые, не чернилами.
- Насыщенность поднимать по склейке рядом с Кукурузником, а не цифрой: ×1,85 на G дал желтизну светлой площади, ×1,6 — норма; тень облаков 0,2 на светлой площади сверху — грязное пятно, там 0,12.
- Значки без слова на телефоне не считываются: флаг не читался как «шоу», белая точка — как «нажми», колесо — как меню (отзыв Нарека 07.10.2026). Кнопка телефона = общепонятный значок (≡, ▶/■, i, домик, стрелки) + короткое слово на языке страницы, зона нажатия ≥ 44×44; слова — BTN_WORD в viewer.js (CONFIG и Кукурузник не меняются).
- Пути машин без маски дорог «на глаз» снова уезжают с проезжей части — маска `ambient.roads` + проверка в сборке (≥ 98 %), а не взгляд на один снимок (круг 4, 07.10.2026).
- Машины и люди, нарисованные кодом даже с акварелью и штриховкой, выглядят игрушечно (лист live4/sprites-all-rejected.png) — для них нужен Gemini; кодом можно только то, что не хуже рисунка (птицы), остальное — мельче/дальше.
- Ночная картинка из дневной через фильтр в движке темнеет ещё раз (NIGHT_DIM для тёмного): фонари и подсветку памятника рисовать с запасом и добавлять `nightLamps` — иначе ночь «мёртвая» рядом с Кукурузником.
- `winlight` на кадре без окон зажигает «окно» на постаменте (тёмная табличка попала в список окон) — на таких кадрах winlight убирать.
- Chrome-расширение может быть не подключено (07.10.2026): задачи с Gemini планировать с запасным путём и сразу говорить, что без Chrome делается кодом.
- Маска дорог из Gemini показала, что пути, положенные «на глаз» по сетке, местами шли по тротуару и краю овала G (круг s2, 08.10.2026): пути класть по маске (`fit_paths_to_roads.py`), проверять обе полосы, а не ось.
- При пересечении «маска Gemini ∩ свои полигоны» свои полигоны надо расширять (--grow): они грубые, по путям, и иначе режут настоящую ширину дороги; края дороги берём у Gemini.
- Красное в самом рисунке (венок, флаги) Gemini-маска считает «дорогой» — исключать красное исходного кадра; нарисованные на дороге машины оставляют в маске дыру.
- Gemini: полноразмерная кнопка скачивания иногда молчит, а Chrome блокирует серию загрузок с сайта — брать превью 1024 px из ответа и один раз разрешить «несколько файлов»; «не могу сгенерировать» лечится инструментом «Создание изображений».
- Спрайт-листы Gemini подписывает виды неточно (у троллейбуса 3/4 «вправо» нарисован влево) — каждый вид сверять глазами до сборки атласа.
- Белый фон листа убирать заливкой от краёв клетки; закрытые белые просветы убирать только у сценок (--holes): у машин так пропадают блики кузова (кремовая «Волга» стала зелёной на тестовом фоне).
- Gemini отдаёт ночь и маски только превью 1024 px — ночь Gemini не замена кадра, а карта света и цвета поверх полного дневного рисунка (`tools/night_from_gemini.py`), иначе карандаш мылится (s4, 08.10.2026).
- Gemini в маске окон/фонарей дорисовывает своё: столбы там, где их нет, и красит кроны «фонарём» — кроны отбрасывать по цвету рисунка, а столбы рисовать в сам рисунок (день и ночь), чтобы свет движка стоял на настоящем столбе.
- Ночь Gemini приносит свою луну и ореол за статуей — небо брать только вертикальным ходом (по строкам), иначе на кадре две луны и светящийся нимб.
- Слой здания на крупном плане захватывает просветы неба (между ног статуи): ночная подсветка «по слою» делает их тёплым пятном — «дыра между ног» на D. Подсветку класть только по силуэту памятника без светлых просветов.
- Места сценок по сетке кадра «на глаз» попадали на крышу и на дорогу — экран показывает кадр с обрезкой и глубиной; ставить и сразу смотреть снимок движка 390×844.
- В headless (swiftshader) CSS- и WAAPI-анимации отстают от часов — для проверки подсказок и искр ставить анимации на паузу и задавать currentTime, а не ловить момент снимком.
- Копия репозитория в облаке может отставать (engine/VERSION был e1.8 при e1.11 на Маке) — перед возвратом файлов сверять каждый с Маком (diff), возвращать только свои правки.
- «Ночь стала комиксной» на Кукурузнике — сначала сравнить код и картинки живого сайта и беты кадр в кадр (origin/main → git archive, снимки ночи и перехода): отличие оказалось не в ночи, а в слое интерфейса (бумажные «i» с чернильной каймой на тёмном). Ночные правки движка — только за флагами кадра/здания (s7, 09.10.2026).
- Закатное солнце (`sun.sunset`) ставилось одним значением на все кадры — на крупных планах оно легло на постамент («пятно как солнце»). Солнце/луну кадра проверять на снимке, только в полосе неба.
- Чёткость ночи: карта ночи Gemini с размытием 2 px переносила «пиксели» Gemini на статую и кроны — карту размывать сильно (9 px) и отдельно для земли и неба; светлая бумажная кайма вырезки ночью светится ореолом — закрашивать цветом неба.
- Повторный `device_commit_files` того же файла из той же выходной папки уносил на Мак СТАРУЮ версию (кэш выходной папки, s7) — для каждой новой версии класть файл по новому пути (`outputs/.../u2/…`) и сверять md5 облако/Мак после записи.
- В облачном Chromium (Playwright) нет H.264 — видео для проверки нужно в VP9 (webm); движок выбирает по canPlayType, iPhone берёт mp4.
- Синемаграф: класть на рисунок не кадр видео, а его отличие от медианы видео — иначе Veo приносит свой оттенок и свои «стоящие» объекты.
