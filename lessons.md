# Уроки chka.am

Агент читает этот файл в начале КАЖДОГО промпта по chka.am.

- Проверять город референса: однажды в кадр попало здание из Батуми.
- «Нет фото с этого ракурса» не значит «нет здания». Проверь карту и план площади.
- Местное знание Нарека важнее интерпретации агента по архивному фото. Если они расходятся, спроси Нарека, а не дорисовывай.
- Gemini не правит кусок кадра. Он генерирует только отдельный фрагмент на однотонном фоне, вписывает его агент.
- Патчи и фрагменты сохранять только в PNG (JPEG портит края).
- Не трогать _проверки во время прогона публикации.
- Gemini только в аккаунте pro.gemini.one1.
- Фикс считается сделанным только после скриншотов при крайних углах наклона, а не по «код выглядит правильно».
- Современные фото годятся только для геометрии зданий. Машины, знаки, указатели, новые фонари в реконструкцию не переносить. Каждое здание сверить по году постройки с эпохой экспоната.
- Обходить технические блокировки (CSP, буфер обмена, передача файлов) разрешено, если это внутри собственных инструментов Нарека и временно. Запрещено: вводить пароли и токены, менять настройки безопасности браузера/системы/аккаунтов, трогать любой аккаунт кроме pro.gemini.one1, отправлять файлы в сторонние сервисы. После обхода — убрать за собой и коротко указать в отчёте.
- Открытый пункт в логе/хэндоффе пишется с сутью: что именно решаем и какие варианты. Плохо: «Шоу флага — решить». Хорошо: «Шоу флага у Ленина: включать или нет; сейчас flag: null».
- Промпт для Cowork — до ~60 строк, иначе обрезается. Большое задание делить на заходы.
- check_site с зоной допуска на панели не видит изменений панели (так прошло подчёркивание 1,5 → 1 px). Панель проверяет Нарек глазами.
- Не открывать файл на запись до чтения (open(f, "w") раньше read): так обнулился 404.html. Сначала прочитать в переменную, потом писать.
- Известный ложный красный check_site: kukuruznik/history pc/top однажды отличался при неизменных файлах (2026-10-05), при повторе прошёл. Если красный только этот снимок и файлы страницы не менялись — повторить проверку один раз; повторился — разбирать, а не ослаблять проверку.
- Полоса неба кадра (`sky.band`) — только НАД объектом: движок рисует облака, птиц и прочую «жизнь» в этой полосе поверх всего кадра, без заслонения зданием. Полоса через статую = облако на груди Ленина (lenin_4, 05.10.2026). new_frame.py теперь режет полосу по верху вырезки; на скриншоте кадра проверять, что в полосе нет объекта.
- scipy `binary_dilation/erosion(..., iterations=0)` = «до упора», а не «ничего»: `grow: 0` в layers.json сделал вырезку на весь кадр (lenin_4, 06.10.2026). Настройку из конфига, которая может быть 0, передавать только через `if n > 0`.
- Коммит — только после зелёных тестов: тесты и `git commit` в одной команде через `&&`, не через `;` (06.10.2026 «lenin show» ушёл в коммит при красном test_new_frame — тест ждал у Ленина один видимый кадр).
- `main` — дерево опубликованного сайта (сборки beta/, lenin/, kukuruznik/), с test/depth-photo у него общий предок из сентября: `git merge main` в рабочую ветку даёт конфликты (docs/LOG.md, kukuruznik/*.html) и тащит сборки в исходники (06.10.2026). Не сливать. «Подтянуть живое» = сверить, что опубликованные кадры/настройки совпадают с веткой (хеши файлов `git rev-parse <коммит main>:lenin/frames/…` против tests/lenin/frames/).
- Параллакс «чинится» только замером объекта ОТНОСИТЕЛЬНО фона вокруг (небо, кроны) на крайних наклонах, а не частей объекта между собой: bldDepth 0.3 сделал голову и постамент заодно, но статуя D всё равно скользила по небу ~21 px и «плыла» на iPhone (06.10.2026). Фон рисуется по карте глубины КАДРА, движок растягивает её контраст 2–98 % — плоскость крупного плана задаётся `depthRaw` + своей картой.
- Скриншоты/гиф с живыми деталями в облаке (swiftshader) — с `?perf=0`: иначе движок через ~5 с видит fps < 45 и выключает детали, и на кадрах «ничего не движется».
- Живость проверять на телефоне по размеру, а не по числу: на B и G было больше объектов, чем у Кукурузника, но люди 4–8 css px — на iPhone это точки, площадь «пустая» (07.10.2026). Человек ≥ 13 css px (`ambient.minPx`), замер — tests/lenin/report/live2/density.md.
- Автоснимки по кадрам (клик «вперёд» N раз) иногда не долистывают — клик во время перехода теряется: однажды «кадр C» оказался кадром B (07.10.2026). Каждый снимок сверять глазами с нужным кадром, прежде чем считать по нему.
