# Форматы роликов chka.am

## Как читать «Пример сценария»
Таблица — раскадровка по секундам. Шаблон — `content/remotion/` (README там): сцена = **карточка** (`cards`), всё поверх — **элементы** (`items`). Примеры в форматах написаны словами старого шаблона склейки (`content/template/`) — переводить по таблице ниже.

| Колонка | Что это | Поле Remotion (`content/scenes/<имя>.json`, `"engine": "remotion"`) | Было в старом шаблоне |
|---|---|---|---|
| `t` | начало–конец сцены, с | карточка `at`, `dur` (карточки перекрываются на 0,1–0,2 с — вход следующей под уход прошлой) | `dur` |
| Сцена | что на экране и откуда | карточка `src`: `image` / `seq: "cap:<id>"` (+ `reverse`) / `video` (+ `start`, `rate`); `w`, `h`, `x`, `y`, `fit`, `look` (`sepia`, `alive`) | `src`, `crop`, `fit`, `bg`, `frame`, `look` |
| Вырезка детали | кусок рисунка крупно | маленькая карточка (`w`/`h` 440–520) + `cam` с приближением 1,8–2,7 на нужную точку | `crop` |
| Камера | из → в, `[cx, cy, z]`, кривая | карточка `cam.from`, `cam.to`, `cam.ease` | то же |
| Вход / событие | как сцена входит и уходит | карточка `enter` (`depth`, `up`, `left`, `right`), `exit` (`left`, `right`, `up`, `down`, `depth`, `none`), `enterDur`, `exitDur` | `trans`, `reveal` |
| Слой | предмет поверх с пружиной | элемент с `on: "<id карточки>"` (едет с ней) — `tag`, `chip`, `dot`, `icon`, `tap`, `stamp`, `counter` | «нужен слой» |
| Бирка | слово, время, место | элемент `tag`: `text`, `variant` (`big` / `tag` / `label`), `at`, `dur`, `x`, `y` (пиксели кадра), `size`, `rot` | `text`: `s`, `at`, `dur`, `size`, `y` (доля полосы) |
| Микро-ритм | мелочи цепочкой 3–5 шт. | элемент `chain`: `at`, `step` (0,1–0,15), `dur`, `items` (`dot`, `chip` с годом / числом / знаком, `tap`) | нет |
| Звук | тип и момент | ставится сам на каждый вход и уход; убрать — карточке `sfx_in` / `sfx_out: "none"`, элементу `sfx: "none"` или `sfx_out: "none"` | `sfx`, `sfx_extra`, `sfx_in` |

- **Съёмка сайта** под таблицей — список кадров для `capture.shots` старого шаблона (`content/template/capture.mjs` снимает в `content/cache/cap/<id>/`, 1080×1920, 30 к/с); Remotion берёт их как `seq: "cap:<id>"`. Снимать столько секунд, сколько карточка на экране, и играть 1:1 (`rate` не трогать) — иначе кадры смешиваются.
- Поля съёмки: `frame` (0 = A, 1 = B … 5 = F), `tod`, `precip`, `tilt`, `speed`, `show`, `card`, `events`.
- Звуки названы по типам библиотеки `content/sfx/` (на 12.11: 3 `pop`, 3 `whoosh`, 1 `click`, 1 `stamp` — Нарек: «этих хватает»). Шаблон сам не ставит один файл дважды подряд; «воздуха» в Remotion нет — это место для тишины.
- Числа камеры и времени в примерах рабочие: их можно переносить как есть и подгонять по листу кадров.
- Пример написан для Погоса-Петроса (материал есть в репозитории) или для Никольского собора (здание №4, `buildings-next/surb-nikolay/`). Для другого здания менять источники, годы и героев, структуру не менять.

## Общее для всех форматов
- Правила монтажа — четыре строки таблицы §0 скилла: движение сквозь стык, вход слоем, слово-бирка, записанный звук.
- Последние 1,5–2 с — бирка `chka.am` (в продающем — `chka.am/t`), не ниже y 1250; в форматах-петлях она стоит на предпоследней сцене, а последний кадр возвращается в кадр 0.
- Архивное фото — только со свободной лицензией по `sources.md`; иначе вместо него рисунок.
- Годы — только подтверждённые (`story.md`, раздел «Факты»); спорные (год сноса Погоса-Петроса, годы собора) в кадр не идут.
- Рисунки и ролики героев сделаны ИИ (Gemini, Veo). TikTok требует метку «AI-generated» для реалистичных сцен и советует её для полностью сгенерированного; наши рисунки не реалистичны, но метку лучше включать при публикации — решает Нарек (https://www.cinerads.com/blog/tiktok-ai-content-policy, https://searchengineland.com/tiktok-new-label-ai-generated-content-432127).
- Подпись поста на hy / ru / en, хэштеги и текст закрепа — в `posts.md` здания, не в ролике.
