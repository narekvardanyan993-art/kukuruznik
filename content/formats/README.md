## Как читать «Пример сценария»
Таблица — раскадровка по секундам. Одна строка = одна сцена файла `content/scenes/<имя>.json`.

| Колонка | Что это | Поле шаблона (`content/template/README.md`; у другого шаблона — то же по смыслу) |
|---|---|---|
| `t` | начало–конец сцены, с | `dur` (без входящего перехода) |
| Сцена | что на экране и откуда | `src`: `image` / `video` / `seq`; пути `repo:`, `kitchen:`, `cap:<id>`; `crop`, `fit`, `bg`, `frame`, `look` |
| Камера | из → в, `[cx, cy, z]`, кривая | `cam.from`, `cam.to`, `cam.ease` |
| Вход / событие | как сцена входит и что происходит внутри | `trans` (`develop`, `dissolve`, `zoom`, `slide`, `flash`), `reveal` (`wipe` / `develop`, `align`, `span`), слой с пружиной |
| Бирка | слово, время появления, место | `text`: `s`, `at`, `dur`, `size`, `y` |
| Звук | тип звука и момент | `sfx`, `sfx_extra`, `sfx_in` текста; файлы — `content/sfx/` |

- **Слой** в раскадровке — отдельный предмет поверх сцены (вырезка героя, бирка, открытка, карточка) со своим входом пружиной. В README шаблона найти поле для слоя; если шаблон слоёв не умеет — взять ближайшее (`reveal`, `text`, `fit: contain` + `frame`) и написать в отчёте «нужен слой» одной строкой. Код шаблона не править.
- **Съёмка сайта** под таблицей — список кадров для `capture.shots`: `frame` (0 = A, 1 = B … 5 = F), `tod`, `precip`, `tilt`, `speed`, `show`, `card`, `events`.
- Звуки названы по типам библиотеки `content/sfx/`. На 12.11 в ней один `click_*` и один `stamp_*`: «другой» в примерах = другой файл того же типа, когда появится; пока чередовать с `pop_*` и не ставить один файл дважды подряд. «Воздух» — фоновый синтез шаблона.
- Числа камеры и времени в примерах рабочие: их можно переносить как есть и подгонять по листу кадров.
- Пример написан для Погоса-Петроса (материал есть в репозитории) или для Никольского собора (здание №4, `buildings-next/surb-nikolay/`). Для другого здания менять источники, годы и героев, структуру не менять.

## Общее для всех форматов
- Правила монтажа — четыре строки таблицы §0 скилла: движение сквозь стык, вход слоем, слово-бирка, записанный звук.
- Последние 1,5–2 с — бирка `chka.am` (в продающем — `chka.am/t`), не ниже y 1250; в форматах-петлях она стоит на предпоследней сцене, а последний кадр возвращается в кадр 0.
- Архивное фото — только со свободной лицензией по `sources.md`; иначе вместо него рисунок.
- Годы — только подтверждённые (`story.md`, раздел «Факты»); спорные (год сноса Погоса-Петроса, годы собора) в кадр не идут.
- Рисунки и ролики героев сделаны ИИ (Gemini, Veo). TikTok требует метку «AI-generated» для реалистичных сцен и советует её для полностью сгенерированного; наши рисунки не реалистичны, но метку лучше включать при публикации — решает Нарек (https://www.cinerads.com/blog/tiktok-ai-content-policy, https://searchengineland.com/tiktok-new-label-ai-generated-content-432127).
- Подпись поста на hy / ru / en, хэштеги и текст закрепа — в `posts.md` здания, не в ролике.
