# Моушн-ролики chka.am (Remotion)

Не склейка кадров, а живая графика в стиле сайта: лист бумаги в клетку, карточки с кадрами вылетают с пружиной, бирки со словами, значки, штамп, счётчик. Каждое появление и уход — звуковое событие.

## Одна команда (из папки репозитория)
```
node content/remotion/build.mjs content/scenes/pogos-02.json
```
Первый раз: `cd content/remotion && npm install` (Remotion сам скачает свой браузер ~100 МБ при первом рендере).

Результат в `content/out/`: `<имя>.mp4` (1080×1920, 30 к/с, H.264, bt709), `<имя>-sheet.jpg` (кадр на каждую секунду), `<имя>-events.json` (все звуковые события), `<имя>-sfx.wav` — только звуки (если есть файлы в `content/sfx/`).

Флаги: `--still 3.2` — один кадр с полями TikTok (красным), без сборки · `--audio-only` — пересвести звук к готовому видео (положили звуки — не надо рендерить заново) · `--browser <путь>` · `--concurrency N`.
Рендер 21 с ролика: ≈3 мин 15 с в облаке (2 ядра).

## Звуки
Файлы по типу: `content/sfx/<тип>*.wav|mp3`, типы `pop`, `whoosh`, `click`, `stamp` (например `pop-1.wav`, `pop-2.wav`). Несколько файлов одного типа — подряд один и тот же не повторяется. Громкость тихая (pop −17 dB, whoosh −19…−24, click −21…−25, stamp −11), сверху ограничитель. Нет файлов — ролик без звука (немая дорожка), разметка в `events.json` остаётся. Скачивать звуки агенту нельзя — их кладёт советник.

## Сценарий (`content/scenes/<имя>.json`, `"engine": "remotion"`)
- `dur`, `fps`, `size`, `safe` [сверху, снизу, справа] — поля TikTok; `bg` — бумага сайта и шаг клетки; `fonts` — шрифты сайта (`engine/fonts`).
- `cards` — карточки по центру: `id`, `at`, `dur`, `src` (`image` | `seq: "cap:<id>"` — кадры сайта из `content/cache/cap/` | `video` с `start`), `cam` {from, to: [cx, cy, zoom]}, `look` (`sepia` или `alive` — серое → цвет), `rot`, `enter` (`depth`, `up`, `left`, `right`), `exit` (`left`, `right`, `down`, `up`, `depth`, `none`), `w`, `h`, `y`. Пути: `repo:` (можно `*` в имени файла), `cap:<id>`.
- `items` — элементы поверх: `tag` (`text`, `variant`: `tag` бирка с дырочкой · `label` ярлык · `big` крупно с подчёркиванием; слова появляются по одному с шагом 70 мс), `icon` (`moon`, `flake`, `bulb`), `tap`, `stamp` (`top`, `mid`, `bottom`, `paper` — на тёмном кадре), `counter` (`from`, `to`, `tick`, `label`). `on: "<id карточки>"` — элемент едет вместе с карточкой, `x`, `y` тогда доли карточки; иначе пиксели кадра. `dur: 0` — не уходит до конца.
- Текст ставить внутри полей TikTok: проверка — `--still <сек>`.

## Код
`src/Promo.tsx` — слои и фильтры «карандаш» / «штемпельная краска»; `src/parts/Paper.tsx` — бумага в клетку; `Card.tsx` — карточка (пружина из глубины, приближение, уход, тень от «высоты»); `Items.tsx` — бирки, значки, тап, штамп, счётчик; `ease.ts` — кривые сайта (`docs/ANIMATION.md`). Значки луны и снежинки — контуры с кнопок просмотрщика, штамп — штемпель главной.
Код рисует только графику интерфейса. Картинки внутри карточек — рисунки Gemini, ролики Veo, архивное фото, кадры сайта.
