# Моушн-ролики chka.am (Remotion)

Не склейка кадров, а живая графика в стиле сайта: лист бумаги в клетку, карточки с кадрами вылетают с пружиной, бирки со словами, значки, штамп, счётчик. Каждое появление и уход — звуковое событие.

## Одна команда (из папки репозитория)
```
node content/remotion/build.mjs content/scenes/pogos-02.json
```
Первый раз: `cd content/remotion && npm install` (Remotion сам скачает свой браузер ~100 МБ при первом рендере).

Результат в `content/out/`: `<имя>.mp4` (1080×1920, 30 к/с, H.264, bt709), `<имя>-sheet.jpg` (кадр на каждую секунду), `<имя>-events.json` (все звуковые события), `<имя>-sfx.wav` — только звуки (если есть файлы в `content/sfx/`), `<имя>-zoom10.jpg` (10 кадров подряд на наезде — смотреть, нет ли рывка), `<имя>-smooth.json` (повторы кадров по карточкам + предупреждения).

Флаги: `--still 3.2` — один кадр с полями TikTok (красным), без сборки · `--audio-only` — пересвести звук к готовому видео (положили звуки — не надо рендерить заново) · `--browser <путь>` · `--concurrency N` · `--frames 0-59` — только часть (проба).
Рендер: 21 с ролика ≈3 мин 15 с, 11,7 с ≈2 мин в облаке (2 ядра).

## Ролик v2: сюжет, подписи, голос, безопасный кадр (13.11, отзыв на story-pogos-01 / 02)
Эталон — `content/scenes/story-pogos-03.json`. Метод — `.claude/skills/chka-motion/SKILL.md` §А–В. У старых сценариев полей `zone` и `story` нет — для них сборка не изменилась.
- **Сюжет:** блок `story` — `message` (посыл одной фразой), `steps` (5–8 шагов подряд: `at`, `dur` 2–4 с, `thought`, `caption`, `vo`, `caption_ru`, `vo_ru`), `stranger` (что понял незнакомец на `"1"`, `"3"`, `"10"`-й с). Нарушение (число и длина шагов, подпись > 6 слов, голос > 45 слов или две фразы в шаге, нет посыла или «незнакомца») — **ошибка сборки**.
- **Подписи:** из `steps[].caption` сборщик делает элемент `caption` — бумажная плашка с крупной фразой, стоит весь шаг. Текст вписывается в прямоугольник `story.caption.box` (по умолчанию `[120, 285, 960, 545]`): размер шрифта подбирается по настоящей ширине строк, 1 или 2 строки, не больше `size` (96). `*слово*` — акцент цветом, `\n` — своя разбивка строк. Звука у подписи нет.
- **Безопасный кадр:** `"zone": "tiktok-2026"` (числа и откуда они — `zone.mjs`). На экране 19,5:9 TikTok срезает по 97 px с боков; текст — x 110–970, y 270–1440, на высоте кнопок (y 820–1440) не правее 840. Карточка — с каждого бока ≥ 48 px видимой бумаги (бок не ближе 145 px к краю кадра) или за краем кадра. Сборка падает с «важное вне зоны» или «фон виден у края». Свои числа — объектом: `"zone": {"bottom": 1260}`.
- **Рамка зоны:** `--still <сек>` — кадр, где красным залито то, что срежет экран или закроет интерфейс, зелёный пунктир — место текста (кадр собирается и при ошибке: видно, что не так).
- **Лист «как в TikTok»:** `<имя>-tiktok.jpg` — кадр каждого шага: сверху обрезка высокого экрана под макетом интерфейса (`assets/tiktok-ui.png`, рисует `assets/make_tiktok_ui.py`), снизу кадр целиком с рамкой зоны.
- **Голос:** сборщик пишет текст озвучки `content/vo/<имя>.txt` (по шагам, с секундами). Файл голоса — `content/vo/<имя>.mp3` (wav, m4a) или по файлу на шаг `content/vo/<имя>/01.mp3, 02.mp3 …` (звук в git не идёт). Один файл режется на фразы сам — по самым длинным паузам (нужна пауза ≥ 0,5 с между фразами) или по `vo.cuts: [[с, по], …]`. Фраза k звучит с начала шага k + `vo.lead` (0,25 с); длиннее шага — ускоряется до ×1,12 с предупреждением, не помещается — предупреждение «удлинить шаг или сократить фразу». Под голосом звуки событий тише (сжатие по голосу, замер −6…−7 dB). Положили голос — `--audio-only`: рендер и Remotion не нужны, хватает node и ffmpeg (на Маке картинка берётся из готового `content/out/<имя>.mp4`). Нет файла — ролик с подписями, ошибки нет. Тайминги — `<имя>-vo.json`.
- **Темп по смыслу:** `"tempo": false`; звуки — только на смысловые события (`sfx`-элементы и входы карточек).
- **Отчёт:** `<имя>-story.md` — таблица шагов (секунды, мысль, подпись и фраза на армянском + перевод) и «что понял незнакомец».
- **Дорогой вид (отзыв на story-pogos-03):** `"fps": 60` (запись сайта 60 к/с — только ×1 и ×2; ролик 24 к/с — ×2,5 кадр в кадр, а ×1,25 с `src.interp: false` идёт «на двойках» без дорисовки и не считается повтором кадров); карточке `enter: "soft"` / `exit: "soft"` (проявляется и тает на месте по кривой iOS, без вылета и отскока), `calm: true` (без покачивания), `rot: 0`; подпись проявляется словами из лёгкого размытия; шагу `underline: true` — под акцентным словом подписи рисуется линия; `"soft": {"lowpass": 4500}` — мягкие звуки; шагу `vo_say` — как фразу писать генератору голоса, если иначе, чем в подписи.
- **Музыка:** `"music": {"file": "repo:content/music/…mp3", "db": -9, "offset": 0, "fade_in": 1, "fade_out": 2}` — идёт под всем роликом, плавно входит и уходит, под голосом приглушается вместе со звуками; попадает и в `-sfx.wav` (там звуки и музыка без голоса). `content/music/` — в .gitignore.
- **Громкость:** `"loudness": -15` — весь звук ролика приводится к −15 LUFS одним усилением, пики не выше −1,5 dB (TikTok и Reels играют около −14…−16; тише — ролик звучит «мёртво»). Голос над музыкой должен быть на 8–10 dB громче (замер: RMS фразы и RMS паузы без звуков).
- **Голос одним файлом с любым именем:** единственный звуковой файл в папке `content/vo/<имя>/` (скачали из ElevenLabs и перетащили, не переименовывая) берётся так же, как `content/vo/<имя>.mp3`. В `content/vo/<имя>.txt` есть текст одним куском с тегами `[pause]` для ElevenLabs v3 / v4.
- **Проверки отдельно:** `--check` — только кадр и сюжет (секунда, ролики не режутся); `--stdin` — сценарий из stdin; `node content/remotion/test_zone.mjs` — эталон зелёный, 11 плохих случаев краснеют; `--dry` — сценарий → свойства и события без рендера.

## Звуки
Файлы по типу: `content/sfx/<тип>*.wav|mp3`, типы `pop`, `out`, `whoosh`, `click`, `key`, `scroll`, `tick`, `stamp` (например `pop-1.wav`, `pop-2.wav`). Несколько файлов одного типа — подряд один и тот же не повторяется. Громкость тихая (pop −17 dB, whoosh −19…−24, click −21…−25, stamp −11), сверху ограничитель. Нет файлов — ролик без звука (немая дорожка), разметка в `events.json` остаётся. Скачивать звуки агенту нельзя — их кладёт советник.

## Плавность и чёткость (12.11, после отзыва на pogos-02)
Сборщик сам следит за тремя причинами рывков и «мыла» и пишет `ВНИМАНИЕ:` в конце, если сценарий их вызывает:
- **Ролики Veo (24 к/с)** не играются напрямую: нужный кусок режется, растягивается по `rate` и дорисовывается до 30 к/с по движению (ffmpeg `minterpolate`) — кадр ролика = кадр видео. Ролик короче карточки → замедление тоже с дорисовкой (раньше 0,5× = каждый кадр дважды, «как 15 к/с»). Кэш — `public/_vid/`.
- **Кадры сайта (`seq`)** играются 1:1. `rate` ≠ 1 → соседние кадры смешиваются (не повторяются); чище — снять с нужной скоростью. Кадров меньше, чем секунд на экране → последний стоит (предупреждение).
- **Приближение** — только `transform: scale` при постоянном размере картинки (смена `width` каждый кадр давала ступеньки 0,25 → 0,05 px за кадр). На карточках нет `will-change` (с ним Chrome растрировал карточку в размере входа и растягивал — резкость падала вдвое).
- **Мыло из источника:** если источник растянут сильнее ×1,15 (вырезка 9:16 из Veo 720p, сильный зум) — предупреждение. Ролик Veo ставить карточкой 16:9 (`w` 940, `h` 560, `fit: contain`).

## Тени
Одна мягкая тень на всё — `soft()` / `softDrop()` / `softText` в `src/parts/ease.ts`: карточки, бирки, фишки, точки, значки, тап, штамп, буквы. Поднятый предмет (во время входа) — тень шире и дальше, лёг — собралась.

## Микро-ритм
`chain` — 3–5 мелочей друг за другом с шагом `step` (0,1–0,15 с), уходят вместе обратной лесенкой; звуки чередуются pop / click тише главных (−24 / −27 dB). Мелочи: `dot` (точка как на просмотрщике, с одним кольцом), `chip` (фишка: год, число, знак `?` `→` `×` `✓`), `tap`. Не больше одной цепочки на сцену и не во время главного раскрытия.
Пример: `{"kind": "chain", "at": 0.6, "step": 0.13, "dur": 0.9, "on": "now", "items": [{"kind": "dot", "x": 0.2, "y": 0.44}, {"kind": "dot", "x": 0.42, "y": 0.63}]}`.

## Живая запись экрана и темп (12.11, отзыв на pogos-03, ролик tour-01)
- **Запись в рамке телефона:** карточка `"frame": "phone"` (тёмная рамка, мягкая тень), `src.video` + `crop: [x, y, w, h]` (срезать статус-бар) + `segs: [{from, to, rate}]` — куски одной записи подряд, у каждого своя скорость (×1,5–2), склейки мгновенные. Длина карточки = сумма `(to − from) / rate`.
- **Без повторов:** запись 60 к/с при `rate` ≤ 2 → кадры отбираются до 30 к/с (`fps`), не дорисовываются (`minterpolate` на буквах интерфейса «плывёт»); дорисовка — только когда кадров мало (Veo, замедление). Скорость — с целым шагом отбора: для 60 к/с это ×1, ×1,5, ×2 (×1,25 или ×0,85 дают шаг 2-3-2 / 1-2-1 — движение дёргается; сборщик предупредит). Паузы в записи (палец отпустил прокрутку, ожидание) — вырезать куском, а не ускорять: иначе на стыке «стоп-кадр».
- **Парение:** `"float": [6, 9]` — карточка всё время чуть плывёт (два синуса, px по x и y): кадр не замирает, даже когда запись стоит, а капля разворачивается (иначе детектор повторов видит «стоп-кадр»).
- **Камера по ключам:** `cam.keys: [[t, cx, cy, zoom, кривая?], …]` (t — секунды от начала карточки), между ключами плавно; пятое поле — кривая отрезка до этого ключа: `in` (разгон в склейку — камера не замирает перед стыком), `out`, `lin`. Перед склейкой ключ с `in`, сразу после — следующий через 1 кадр (перескок прячется в склейке). **Поза по ключам:** `keys: [{t, x, y, s, r, rx, ry}]` — сдвиг, масштаб, поворот, наклон в 3D (финал «телефон наклоняется»).
- **Приколотые элементы:** `"pin": true` — `x`, `y` (`x2`, `y2`) в долях кадра источника (после `crop`), точка едет за камерой карточки (тап по клавише, точка на портале).
- **Капля:** значки, бирки, фишки, точки, куски линейки входят 0 → 1,12 → 0,96 → 1 за 0,25 с со сплющиванием, уходят за 0,18 с со звуком `out` (`drop()` в `ease.ts`).
- **Линейка:** `{"kind": "ruler", "x", "y", "x2", "y2", "n": 5, "step": 0.08}` — пунктир из n кусочков, каждый каплей и с `tick`.
- **Звук без картинки:** `{"kind": "sfx", "at", "type": "scroll"}` — прокрутка, листание, переход внутри записи. У любого элемента `sfx: "<тип>"` — свой звук входа (`key_1`, `key_enter`), `sfx_out: "<тип>"` — свой звук ухода. Тип = начало имени файла в `content/sfx/`.
- **Плотность звука:** в `-events.json` и `-smooth.json` — `density` (`per_sec`, `max_gap`, `max_together`); тишина > 0,5 с или 3 звука разом → `ВНИМАНИЕ:`. Каждый звук слегка меняет высоту (±4 %), чтобы один файл подряд не звучал одинаково. `"tempo": false` в сценарии — выключить эту проверку (выдох перед раскрытием).

## Ролик-фильм без музыки (12.11, отзыв на tour-01, ролик tour-02)
- **«До / после» шторкой:** у карточки `compare: {"image": "repo:…", "cam": [cx, cy, z], "keys": [[t, доля x, кривая?], …], "show": t}` — вторая картинка лежит поверх `src` и видна слева от ручки; ручка (бумажная черта + кружок ‹ ›) едет по ключам сама, появляется каплей в `show`. Тики на старте и финише — отдельными `sfx`.
- **Лупа:** `{"kind": "loupe", "on": "<карточка>", "pin": true, "x", "y", "size": 300, "mag": 2}` — круг со стеклом и ручкой над точкой кадра, внутри тот же кадр крупнее; входит и уходит каплей.
- **Значок наклона:** `icon` с `name: "tilt"` (телефон с дугами-стрелками, качается). Сам наклон — ключи позы телефона (`ry` ±9–10°) + камера карточки в обратную сторону (`cam.keys` с приближением ≥ 1,08, иначе сдвигать нечем).
- **Длинный звук:** у `sfx` — `len` (сколько секунд звучит, по умолчанию 1,2), `fade` (затухание в конце), `offset` (с какой секунды файла). Пока длинный звук звучит, проверка тишины считает это звуком.
- **Громкость элемента:** `gain` — звук входа (dB), `gain_out` — звук ухода.
- **Фон «комната»:** `"room": {"db": -31, "lowpass": 380}` — тёмный шум очень тихо по всему ролику (появляется и уходит плавно); ролик без музыки не звучит «в вакууме».
- **Темп и паузы:** `"tempo": {"max_gap": 1.45, "min_pause": 1.0}` — допустимая тишина и минимальная пауза; `"moments": [{"name", "from", "to"}]` — главные моменты (пауза на главном): в `-events.json` и `-smooth.json` — длина паузы и сколько звуков в ней (`sec_per_sound` < 0,6 → `ВНИМАНИЕ:` «в паузе реже»).
- **Стоп-кадр из записи:** тот же кусок на `rate: 0.5` (запись 60 к/с → шаг 1, каждый кадр один раз); медленнее 0,5 — дубли.

## Сценарий (`content/scenes/<имя>.json`, `"engine": "remotion"`)
- `dur`, `fps`, `size`, `safe` [сверху, снизу, справа] — поля TikTok; `bg` — бумага сайта и шаг клетки; `fonts` — шрифты сайта (`engine/fonts`).
- `cards` — карточки по центру: `id`, `at`, `dur`, `src` (`image` | `seq: "cap:<id>"` — кадры сайта из `content/cache/cap/`, `reverse: true` — задом наперёд | `video` с `start`, `rate`), `cam` {from, to: [cx, cy, zoom]}, `look` (`sepia` или `alive` — серое → цвет), `sfx_in` / `sfx_out` (`none` — без звука), `rot`, `enter` (`depth`, `up`, `left`, `right`), `exit` (`left`, `right`, `down`, `up`, `depth`, `none`), `w`, `h`, `y`. Пути: `repo:` (можно `*` в имени файла), `cap:<id>`.
- `items` — элементы поверх (кроме того — `ruler`, `sfx`, см. выше): `tag` (`text`, `variant`: `tag` бирка с дырочкой · `label` ярлык · `big` крупно с подчёркиванием; слова появляются по одному с шагом 70 мс), `icon` (`moon`, `flake`, `bulb`, `sun`, `sunset`, `tilt`), `tap`, `stamp` (`top`, `mid`, `bottom`, `paper` — на тёмном кадре), `counter` (`from`, `to`, `tick`, `label`; без `to` — стоит, не щёлкает: места меняются только после настоящей продажи), `dot`, `chip` (`text`), `chain` (выше). Любому элементу: `sfx: "none"` — без звука, `sfx_out: "none"` — уход без звука. `on: "<id карточки>"` — элемент едет вместе с карточкой, `x`, `y` тогда доли карточки; иначе пиксели кадра. `dur: 0` — не уходит до конца.
- Текст ставить внутри зоны TikTok: у сценария с `zone` это проверяет сборка, рамка — `--still <сек>`; `safe` — старые поля для сценариев без `zone`.
- `check_zoom` (сек) — откуда брать 10 кадров подряд для `-zoom10.jpg` (по умолчанию — середина карточки с самым сильным наездом). `seed` — какой файл звука какого типа.

## Код
`src/Promo.tsx` — слои и фильтры «карандаш» / «штемпельная краска»; `src/parts/Paper.tsx` — бумага в клетку; `Card.tsx` — карточка (пружина из глубины, приближение, уход, тень от «высоты»); `Items.tsx` — бирки, значки, тап, штамп, счётчик, точки, фишки, подпись шага (`caption`); `zone.mjs` — безопасный кадр и метод сюжета (проверки сборки), `test_zone.mjs` — их самопроверка; `ease.ts` — кривые сайта (`docs/ANIMATION.md`) и общая мягкая тень. Значки луны и снежинки — контуры с кнопок просмотрщика, штамп — штемпель главной.
Код рисует только графику интерфейса. Картинки внутри карточек — рисунки Gemini, ролики Veo, архивное фото, кадры сайта.
