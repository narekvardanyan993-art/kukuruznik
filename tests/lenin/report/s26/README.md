# s26 — открытка «в сторис» (шаг 9а, движок e1.27)

Всё снято **настоящим рендером Chrome** (облако, swiftshader, телефон 390×844 @2x и ПК 1440×900), скрипт `postcards.mjs`, листы и зоны — `sheets.py`.

## Что получилось
- Кнопка в меню «Открытка в сторис» (+ «Настроить» рядом). Одно нажатие: кадр ровно как на экране (день/ночь/снег/облака/птицы) → 1080×1920.
- Поверх кадра: музейная табличка (название + годы из `building.json → postcard`, язык подписи; своя строка — если задана), почтовый штемпель
  «ԵՐԵՎԱՆ» с сегодняшней датой (снизу — страна на языке подписи), подпись `chka.am/<здание>` на табличке.
- Штемпель и табличка ложатся туда, где на кадре меньше рисунка (небо, пустая площадь), а не на памятник; на тёмном (ночь) штемпель светлыми чернилами.
- Телефон: системное «Поделиться» с файлом JPEG (там «Сохранить изображение», Instagram, TikTok). Вызов — в том же нажатии (`sameTask: true`
  в `checks.json`); если iOS всё же откажет — плашка «Открытка готова — нажмите, чтобы сохранить». ПК: скачивание PNG.
- «Настроить»: превью, язык подписи hy/ru/en, своя строка до 40 знаков, «Старая плёнка» (выцветание, виньетка, зерно), «Сохранить». Настройки запоминаются.

## Файлы
- `sheet-lenin.jpg`, `sheet-kukuruznik.jpg` — 18 открыток на здание: день / ночь / снег × hy / ru / en × без плёнки / с плёнкой.
- `card-*.jpg` — полноразмерные образцы 1080×1920; `card-cfg-save-lenin.jpg` — сохранённая из «Настроить» (en, своя строка, плёнка).
- `zones-lenin.jpg`, `zones-kukuruznik.jpg` — разметка: красное — под кнопками/подписью TikTok (сверху 130, снизу 484, справа 140, слева 44),
  синее — Instagram Stories (сверху/снизу 250), зелёная рамка — зона открытки (64 / 250 / 150 / 500), жёлтый контур — что нарисовано поверх.
- `zones.json` — замер: пикселей поверх кадра вне зелёной зоны — **0** на всех 6 снимках (оба здания × день/ночь/снег).
- `checks.json` — кнопки: одно нажатие → share JPEG 1080×1920, ПК → PNG, «Настроить» → share, настройки в памяти, окно закрывается, 0 ошибок JS.
- `fps.json` — частота кадров до/после в одинаковых условиях облака (swiftshader ~1 кадр/с — только сравнение): равна; в цикле кадра нового кода нет.
- `ui-phone-lenin.jpg` (меню, окно «Настроить», окно с настройками), `ui-pc-kukuruznik.jpg` (панель ПК).
