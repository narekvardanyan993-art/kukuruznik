# s14 — насыщенность G: видео / ?cine=0 / видео со сдвигом цвета

Облачный Chrome 390×844, интерфейс скрыт, кадр G, видео заморожено на 4 с. «Сдвиг как на iPhone» — ролик G, перекодированный с gamma 1,15,
насыщенностью ×0,75 и +3 % яркости (весь кадр ролика вместе с калибровочной полоской). S — насыщенность HSV. «Неподвижное в маске» — пиксели
маски видео, где вода/листва в этот момент не движется (3023 px из 5730) — там раньше и ложился сдвиг цвета ролика.

| вариант | S, весь кадр | Δ к ?cine=0 | S, неподвижное в маске | Δ к ?cine=0 |
|---|---|---|---|---|
| ?cine=0 (только рисунок) | 58.7 | +0.0 % | 123.6 | +0.0 % |
| видео e1.18 (отличие от рисунка + калибровка) | 58.5 | -0.3 % | 120.8 | -2.2 % |
| видео со сдвигом цвета «как на iPhone» + калибровка | 58.8 | +0.1 % | 123.4 | -0.1 % |
| видео со сдвигом цвета, полоска стёрта (без калибровки) | 58.6 | -0.1 % | 113.4 | -8.2 % |

Ролики со сдвигом подменены через перехват запроса и не перематываются — стоят на начале (кадр = рисунок), то есть вся маска «неподвижна»: ровно тот случай, где сдвиг декодера раньше красил площадь.
Цель — разница ≤ 3 %. Без калибровки сдвиг декодера виден в маске; с калибровкой — выправлен. На самом iPhone — только глазами (G и G с ?cine=0).
