# Ленин: параллакс «наклеенного» памятника (2026-10-02)

Причина (в движке, не правилась): `engine/prep.js` двигает здание (памятник + лестницу) ОДНИМ жёстким куском со средней глубиной по маске (`meanD`), а землю — по карте глубины `_depth.webp`. У Ленина лестница уходит к зрителю: мостовая у нижнего края лестницы по карте глубины 0.6–0.7, среднее по зданию 0.40 → при наклоне лестница едет в одну сторону, мостовая под ней — в другую.

Сравнение с Кукурузником (эталон): настройки Ленина уже слабее движковых по умолчанию, которые у Кукурузника (`tuning: {}`): MAX_SHIFT_X 0.0156 против 0.02, MAX_SHIFT_Y 0.0094 против 0.012, ZOOM_NEAR 0.0156 против 0.02, BREATH 0.0031 против 0.004. Здание у Ленина едет на −1.0 css px при полном наклоне (Кукурузник −2.8 px), мостовая внизу кадра +6.1 px (Кукурузник +7.8). Менять `building.json` не пришлось.

Правка (только файлы Ленина): `source/depth_pin_ground.py` запускается после `tools/build_building_layers.py` и правит `lenin_1_depth.webp`: у мостовой вокруг вырезки (ниже линии горизонта, строка ~880 из 1365) глубина у контура равна средней по зданию и плавно (smoothstep, радиус 260 px) возвращается к исходной карте — смещение мостовой растёт от контакта с лестницей к зрителю. Перцентильная нормализация движка (2%/98%) сохранена, глубина деревьев и неба не менялась.
