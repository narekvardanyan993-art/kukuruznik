# Кукурузник — постоянные движения (эталон живости), разбор 06.10.2026

Источник: kukuruznik/building.json (6 кадров), engine/viewer.js (шейдер), engine/details.js (живые детали), engine/config.json.
«Постоянные» = идут сами, без кнопки шоу. Всё отключается первым, если fps < 45 (сначала детали, потом ветер).

## На всех 6 кадрах (движок, всегда)
| Движение | Где в движке | Как выглядит |
|---|---|---|
| Облака плывут | details.js drawClouds, полоса `sky.band`, `sky.clouds` (1–3) | 1–3 акварельных облака медленно идут через небо, по кругу |
| Солнце мерцает | details.js drawSun, `sun.day` | ореол и лучи «дышат»; закат — низкое красное, ночь — луна |
| Одиночные птицы | details.js drawAmbientBirds (3 птицы) | машут крыльями, пересекают небо |
| Ветер в кронах | шейдер, карта `_env` (G/B — высота и фаза дерева), `wind` кадра (1; у крупного плана 1,9), WIND_AMP_PX 2,5 | верхушки деревьев качаются, у каждого дерева своя фаза 5–7 с |
| Тени облаков | шейдер cloudShadow, `cloudShadow` кадра (0,12; у крупного плана 0,26) | мягкие пятна тени ползут по земле и фасадам |
| «Дыхание» камеры | viewer.js BREATH_AMPLITUDE 0,004, период 6 с | весь кадр чуть плавает даже без наклона телефона |
| События раз в 8–15 с | details.js KINDS по `life` кадра (день/закат/ночь) | самолёт со следом, стайка птиц, клин журавлей, бумажный змей, воздушный шар, орёл, небесный фонарик, бабочки над газоном, светлячки, мотыльки у фонаря, свет в окне |

## По кадрам
| Кадр | Свои постоянные движения сверх общих |
|---|---|
| v_angle_0 | газон `lawn` → бабочки днём, светлячки ночью; ночные фонари (5) с «дыханием» света |
| v_angle_1 | флаг `flag` колышется (шейдер, волна внутри прямоугольника); газон; 7 ночных фонарей |
| v_angle_2 | флаг колышется; 5 фонарей `lamps` + 8 ночных |
| v_angle_3 | газон (бабочки/светлячки); 8 ночных фонарей |
| v_angle_4 | 7 фонарей, 8 ночных; полоса неба узкая — облака/птицы высоко |
| v_angle_5 (крупный план, `closeUp`) | блики скользят по окнам (`glints`); птица садится на кромку крыши и улетает (`perch`, цикл); флаг на мачте (`mast`); ветер 1,9, тени облаков 0,26 |
